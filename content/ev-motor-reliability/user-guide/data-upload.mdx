# 실측 데이터 올리기

실차 시험 엑셀 파일을 올려 온도·토크·열피로 판정 결과를 받습니다.

## 시작 전에 필요한 것

올릴 파일은 다음 조건을 맞춰야 합니다.

- 확장자 `.xlsx`. CSV와 `.xls`는 받지 않습니다.
- 크기 50MB 이하.
- 첫 번째 시트만 읽습니다. 1·2행은 비워 두거나 제목을 두고, 3행에 열 이름, 4행에 단위, 5행부터 측정값을 둡니다. 4행 단위는 읽지 않고 버립니다.
- 측정 간격은 1초여야 합니다. 이동 평균과 온도 상승률 계산이 1초 간격을 가정합니다.
- 3행에 아래 여섯 열 이름이 글자 그대로 있어야 합니다. 다른 열은 무시합니다.

| 열 이름 | 단위 | 내용 |
|---------|------|------|
| `time` | s | 경과 시간 |
| `Veh_Velocity` | kph | 차량 속도 |
| `Mot Temp` | °C | 모터 온도 |
| `Igbt Temp` | °C | 인버터 IGBT 온도 |
| `Heatsink Temp` | °C | 히트싱크 온도 |
| `Mot Tq` | Nm | 모터 토크(양수는 구동, 음수는 회생) |

파일 이름은 `SAMPLE_차종_EV_프로토콜_조건_모드.xlsx` 형식이면 차종·프로토콜·조건·모드가 목록에 따로 표시됩니다. 형식이 다르면 네 칸 모두 `unknown`으로 나옵니다.

## 절차

1. 왼쪽 메뉴에서 **실측 데이터**를 누릅니다. **실측 데이터 관리** 화면이 열립니다.
2. **엑셀 업로드 (.xlsx)** 버튼을 누르고 파일을 고릅니다.
3. 분석이 끝날 때까지 기다립니다. 진행 중에는 "분석 중... (수십 초 소요될 수 있습니다)"가 보입니다.
4. "업로드 완료" 알림이 뜨면 **업로드 목록**에 파일이 추가되고 아래에 결과가 열립니다.
5. 예전에 올린 결과를 다시 보려면 **업로드 목록**에서 그 줄을 누릅니다. **파일명 또는 차종 검색** 칸으로 목록을 줄일 수 있습니다.

## 결과 확인

**분석 결과** 아래에 다섯 묶음이 나옵니다.

| 묶음 | 보여 주는 것 |
|------|--------------|
| **시험 개요** | 차종, 프로토콜, 조건, 모드, 샘플 수, 시험 시간 |
| **온도 프로파일** | 모터·IGBT·히트싱크 채널별 평균, 표준편차, 최소, 최대, P95, P99 |
| **토크-속도 분포** | 역행·회생·정지 비율, 피크 출력, 회생 피크, 최대 속도, **듀티 사이클** 차트 |
| **열적 한계 판정** | 채널별 최대 온도, 한계, 마진(°C, %), 상태(SAFE, WARNING, CRITICAL) |
| **신뢰성 평가 (채널별 Damage Cycle)** | 채널별 열 사이클 수, 평균·최대 ΔT, 수명 사이클, Miner 누적 손상, 잔여 수명, 판정(PASS, MARGINAL, FAIL) |

판정 기준과 계산식은 [실측 데이터 판정 기준](/ev-motor-reliability/user-guide/sample-analysis)에 있습니다. 이 화면은 결과 파일을 내려받는 기능이 없습니다. 차트를 그림 파일로 받으려면 [실측 데이터 차트 파일 만들기](/ev-motor-reliability/user-guide/visualization)를 봅니다.

## 결과 지우기

목록 줄 끝의 휴지통 아이콘을 누르면 확인 없이 바로 지워집니다. "삭제 완료" 알림이 뜨면 끝입니다.

## 잘 안 될 때

- "업로드 실패"에 필수 컬럼 누락이 나오면 3행의 열 이름이 위 표와 글자까지 같은지 봅니다. 공백과 대소문자도 같아야 합니다.
- 50MB를 넘는 파일은 시험 구간별로 나눠 올립니다.
- 같은 접속 주소에서 1분에 10번 넘게 올리면 잠시 막힙니다. 1분 뒤 다시 올립니다.
- 그 밖의 증상은 [문제 해결](/ev-motor-reliability/admin-guide/troubleshooting)을 봅니다.
