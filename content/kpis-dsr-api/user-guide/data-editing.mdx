# 갑지·을지 고치기

날짜 하나의 갑지·을지를 표로 열어 칸을 고칩니다. 날짜 자료를 지우거나 처리 상태를 초기화하는 방법도 이 쪽에 있습니다.

## 시작 전에 필요한 것

- 승인된 계정. 날짜 지우기와 상태 초기화는 관리자만 합니다.
- 고칠 수 있는 줄은 미보고 줄과 반송 줄뿐입니다. 접수된 줄, 포털로 낸 줄, 결과 미확인 줄은 잠겨 있습니다. 접수된 줄을 고치려면 정정·취소나 반송신청을 씁니다([반송 줄 고쳐 다시 보고하기](/kpis-dsr-api/user-guide/return-management)).

## 날짜 열기

1. 사이드바 **자료**에서 **데이터 관리**를 누릅니다. 날짜마다 **갑지**, **을지**, **보고**, **미보고**, **오류** 건수와 **상태**가 보입니다.
2. 고칠 날짜를 누릅니다. **대시보드** › **할 일**의 `⋯` 메뉴에서 **보고 상세 열기**를 눌러도 됩니다.
3. 사이드바 **공급구분**에서 **출고**, **반품**, **폐기**, **정정**, **취소** 가운데 하나를 고릅니다.

날짜를 열면 미보고·반송 줄에 코드매핑, 마스터 매칭, 단가오류 자동수정, 규격보정, 규칙이 자동으로 적용됩니다. 적용 내용은 **도구** › **수정이력**에 남습니다.

## 칸 고치기

1. 표에서 고칠 칸을 누르고 값을 넣습니다.
2. 칸에서 벗어나면 그 줄이 바로 저장됩니다. 규격보정이 필요한 줄이면 한 번 더 고쳐 저장합니다.
3. 오류·경고가 있는 줄로 가려면 사이드바의 **오류** 또는 **경고**를 누릅니다([오류·경고 줄 고치기](/kpis-dsr-api/user-guide/validation)).

칸마다 쓰는 방법이 조금 다릅니다.

| 칸 | 고치는 법 |
| --- | --- |
| 표준코드 | 한 번 누르면 표준코드 검색이 열리고, 두 번 누르면 직접 고칩니다 |
| 공급수량 | 공급금액이 있으면 공급금액 ÷ 수량으로 공급단가를 다시 계산합니다 |
| 공급단가 | 공급금액이 있으면 공급금액 ÷ 단가로 공급수량을 다시 계산합니다 |
| 반송사유 | 코드 목록(DC·DE·DH 등)에서 고릅니다. 단가 코드를 고르면 그 표준코드에 대해 기억합니다 |
| 보고상태 | 읽기 전용입니다. 미보고·접수·반송·결과 미확인 같은 상태를 보여 줍니다 |

## 보기 바꾸기

- 기본은 작업용 보기입니다. **컬럼 설정**에서 볼 열과 순서를 고르고, **기본값**으로 되돌립니다. 고른 설정은 사용자마다 저장됩니다.
- **갑지 양식**을 누르면 KPIS 갑지 양식 21칸(A~U)을 원래 순서와 머리글로 봅니다. 이 보기에서는 열 설정을 쓰지 않습니다.
- 위쪽 검색 칸에 제품명 또는 표준코드를 넣어 줄을 거릅니다.

## 결과 확인

- 고친 칸은 표에 바로 보이고 **도구** › **수정이력**에 수동 수정으로 남습니다.
- 다른 곳에서 먼저 바뀐 줄, 이미 보고된 줄처럼 반영하지 못한 줄이 있으면 저장 오류가 뜨고 그 줄은 데이터베이스 내용으로 되돌아갑니다. 화면을 다시 열고 고칩니다.
- 다른 날짜로 옮기면 고친 줄을 먼저 저장한 뒤 날짜가 바뀝니다.

## 엑셀로 내보내기

1. 위쪽 **내보내기**를 누릅니다. 버튼 옆 숫자는 지금 걸러진 줄 수입니다.
2. 저장하지 않은 수정이 있으면 먼저 저장한 뒤, 그 날짜의 공급구분별 갑지·을지를 엑셀로 내려받습니다.

내보내기는 데이터베이스에 저장된 자료를 그대로 읽어 내려받고, 날짜 카드의 **엑셀 다운로드**처럼 다운로드 이력을 남깁니다. 다운로드 이력은 포털 제출을 뜻하지 않습니다([KPIS에 보고하기](/kpis-dsr-api/user-guide/pdf-export)).

## 날짜 자료 지우기·상태 초기화

**데이터 관리**의 **작업** 칸에서 합니다.

1. **상태 초기화**를 누르면 그 날짜의 처리 상태와 오류 정보가 초기화되어 다시 검증할 수 있는 상태가 됩니다.
2. **삭제**를 누르면 그 날짜의 갑지·을지가 모두 지워집니다. 되돌릴 수 없습니다.
3. 확인 창에서 **초기화** 또는 **삭제**를 누릅니다.

> **주의:** 접수, 포털 제출, 결과 미확인, 엑셀 다운로드처럼 보고 흔적이 있는 날은 지우거나 다시 실을 수 없습니다. 보고한 날의 자료가 바뀌었으면 [공급 자료 가져오기](/kpis-dsr-api/user-guide/daily-reports)의 "원천이 바뀐 날 다시 싣기"를 따릅니다.

## 잘 안 될 때

- 칸이 고쳐지지 않으면 **보고상태**를 봅니다. 잠긴 줄입니다.
- 표가 비어 있으면 그날 자료가 없는 것입니다. [공급 자료 가져오기](/kpis-dsr-api/user-guide/daily-reports)로 받습니다.
