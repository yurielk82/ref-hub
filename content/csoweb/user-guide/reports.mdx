# 월별 합계와 품목·공지 보기

> **참고:** CSO 정산 포털의 정산 업무는 2026-09-29에 다른 정산 시스템으로 옮겼습니다. 이 쪽은 운영 당시 화면 기준 기록입니다.

회원사가 여러 달의 수수료 흐름, 품목별 수수료 기준, 관리자 공지를 확인하는 방법입니다. 대상은 회원사 담당자입니다. 한 달 치 내역은 [정산서 조회하기](/csoweb/user-guide/dashboard)에서 봅니다.

## 여러 달 합계 보기

1. 위쪽 메뉴에서 **월별 합계**를 누릅니다.
2. **월별 수수료 합계** 화면 위쪽 카드에서 전체 기간 값을 확인합니다.
3. 아래 **정산월별 합계** 표에서 달마다 값을 비교합니다.

카드는 다음과 같습니다.

| 카드 | 뜻 |
|------|------|
| **총 정산월** | 볼 수 있는 정산월 수입니다. |
| **총 데이터 건수** | 그 기간 정산 줄 수입니다. |
| "열 이름 (전체)" | 관리자가 합계 열로 정한 수수료·합계 열마다 하나씩, 전체 기간 합계를 원 단위로 보여 줍니다. |

**정산월별 합계** 표의 열은 **정산월**, **건수**, 그리고 관리자가 정한 합계 열입니다. 가장 최근 달에는 **최신** 표시가 붙고, 맨 아래 **총합계** 줄이 전체 기간을 더합니다.

> **참고:** 표에 "관리자가 합계 표시 컬럼을 설정하지 않았습니다"가 나오면 관리자에게 합계 열 설정을 요청합니다.

## 홈 화면 읽기

로그인하면 **홈**이 먼저 열립니다. 홈은 회원사 이름과 **연간 정산 현황**을 보여 줍니다.

| 영역 | 내용 |
|------|------|
| **수수료**, **거래처 수**, **제품 수** 카드 | 최근 달 값과 전월 대비 증감률 |
| **월별 추이** | 달마다 수수료 흐름 |
| **제품별 수수료 비중** | 제품별 몫 |
| **거래처 TOP 5** | 수수료가 큰 거래처 다섯 곳 |
| **거래처 변동** | 새로 나온 거래처, 빠진 거래처, 변동 없는 거래처 수 |

홈 아래 바로가기에서 **정산서 조회**, **월별 합계**, **CSO 품목**, **내 정보**로 바로 갈 수 있습니다.

## 품목별 수수료 기준 보기

**CSO 품목**은 회사가 관리하는 품목 기준표입니다. 모든 회원사가 같은 표를 봅니다.

1. 위쪽 메뉴에서 **CSO 품목**을 누릅니다.
2. 찾을 품목이 있으면 검색 칸에 품목명이나 대표코드를 입력합니다.
3. 표에서 **단가**, **수수료율**, **수수료 환산금액**을 확인합니다.

표의 열은 **연번**, **품목명**, **대표코드**, **약효군**, **제형**, **단가**, **수수료율**, **수수료 환산금액**입니다.

## 공지 읽기

1. 위쪽 메뉴에서 **공지사항**을 누릅니다.
2. 읽을 공지의 **자세히**를 누릅니다.
3. 첨부 파일이 있으면 **다운로드**를 누릅니다.

**고정** 표시가 붙은 공지는 목록 맨 위에 남습니다. 관리자는 이곳에 사업자등록증, 공문, 정산 안내를 올립니다.

## 잘 안 될 때

- 원하는 달이 없으면 관리자가 정한 **조회 기준 연월**보다 앞선 달일 수 있습니다. 관리자에게 묻습니다.
- **CSO 품목**에 "표시할 CSO 품목이 없습니다."가 나오면 관리자가 품목 기준표를 아직 등록하지 않은 것입니다. 관리자에게 묻습니다.
- 다른 문제는 [자주 묻는 질문](/csoweb/user-guide/checklists)을 봅니다.
