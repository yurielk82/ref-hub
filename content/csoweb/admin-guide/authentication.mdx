# 인증과 권한

> **참고:** CSO 정산 포털의 정산 업무는 2026-09-29에 다른 정산 시스템으로 옮겼습니다. 이 쪽은 운영 당시 구성의 기록입니다.

이 쪽은 포털이 누구를 어떻게 로그인시키고, 로그인한 사람에게 어떤 자료를 보여 주는지 정리합니다.

## 로그인 방식

포털은 Supabase Auth를 쓰지 않고 자체 JWT(JSON Web Token) 인증을 씁니다. 로그인 아이디는 사업자번호입니다.

| 항목 | 값 |
|------|------|
| 토큰 | `jose` 라이브러리, HS256 서명 |
| 유지 시간 | 24시간. 갱신 토큰은 없어 24시간마다 다시 로그인합니다. |
| 보관 | httpOnly 쿠키, SameSite=Lax, 운영 환경에서는 Secure |
| 비밀번호 저장 | bcrypt 해시(12 rounds) |
| 화면 보호 | 화면과 API가 요청마다 세션을 다시 확인합니다. |

## 로그인 뒤 어디로 가는가

로그인에 성공하면 계정 상태에 따라 첫 화면이 정해집니다. 위에서부터 차례로 따집니다.

1. 임시 비밀번호를 받은 계정은 **비밀번호 변경 필요** 화면으로 갑니다.
2. 승인 전 계정은 업체 정보가 비었으면 **회원 정보 설정**, 서류가 비었으면 **서류 제출**로 갑니다. 둘 다 채웠으면 "승인 대기 중입니다." 안내와 함께 로그인이 거절됩니다.
3. 승인된 계정도 업체 정보나 서류가 비었으면 같은 화면으로 갑니다.
4. 나머지는 관리자는 관리자 **대시보드**, 회원사는 **홈**으로 갑니다.

## 비밀번호 규칙

| 항목 | 일반 계정 | 테스트 계정 |
|------|------|------|
| 최소 길이 | 6자 | 4자 |
| 영문·숫자 | 둘 다 포함 | 제한 없음 |
| 임시 비밀번호 뒤 새 비밀번호 | 초기화로 받은 임시 비밀번호 그대로, 사업자번호, 그 끝 다섯 자리는 쓸 수 없음 | 같음 |

- 로그인에 다섯 번 실패하면 계정이 잠기고, 등록된 이메일로 비밀번호 변경 링크가 자동으로 갑니다.
- 비밀번호 찾기 인증코드와 변경 링크는 30분 동안 한 번만 쓸 수 있습니다.

## 계정 종류와 볼 수 있는 자료

| 계정 | 볼 수 있는 정산 자료 | 엑셀 다운로드 | 관리자 화면 |
|------|------|------|------|
| **일반** 회원사 | CSO 매칭으로 이어진 업체 표기의 자료만. **조회 기준 연월**보다 앞선 달은 숨김 | 하루 5회 | 없음 |
| **관리자** | 전체 | 제한 없음 | 모두 |
| **뷰어** 관리자(목록에 **보기 전용** 표시) | 전체 | 제한 없음 | 조회만. 업로드 같은 변경은 거절 |
| **테스트** 계정 | 테스트로 바꾸면 그 계정의 매칭 표기 앞에 `[TEST]`가 붙어 실제 정산 자료와 이어지지 않음 | 하루 5회 | 없음 |

계정 등급은 관리자가 **회원 관리**의 **회원 정보 수정**에서 **회원 등급**으로 정합니다.

회원사가 볼 자료는 사업자번호로 정해집니다. 서버가 CSO 매칭 표에서 그 사업자번호에 이어진 업체 표기를 모두 찾고, 정산 자료 가운데 그 표기의 줄만 돌려줍니다. 매칭 구조는 [데이터베이스](/csoweb/admin-guide/database)에 있습니다.

## 거래처 화면 보기

관리자는 회원사가 보는 화면을 그대로 확인할 수 있습니다.

1. 오른쪽 위 관리자 계정 메뉴를 엽니다.
2. **거래처 화면 보기** 아래 검색 칸에 업체명이나 사업자번호를 입력하고 회원사를 고릅니다.
3. 화면 위 "거래처 화면 확인 중: 업체명 (번호)" 띠를 확인합니다.
4. 끝나면 **관리자 모드로 돌아가기**를 누릅니다.

이 모드에서는 조회와 다운로드만 됩니다. 승인된 일반 회원사만 고를 수 있고, 관리자 계정과 테스트 계정은 고를 수 없습니다.

## 요청 수 제한

같은 곳에서 1분 동안 보낼 수 있는 요청 수에 상한이 있습니다. 넘으면 "요청이 너무 많습니다. 잠시 후 다시 시도해주세요."가 나옵니다.

| 동작 | 1분 상한 |
|------|------|
| 로그인 | 10회 |
| 회원가입 | 5회 |
| 비밀번호 찾기·재설정·변경 | 5회 |
| 정산서 업로드 | 10회 |
