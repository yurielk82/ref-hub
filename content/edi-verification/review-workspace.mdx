# 검토 집계 화면

프로엠알 EDI 첨부를 원본과 대조한 검토 기록을 모아 보여 주는 화면입니다. 허용된 Google 계정으로 로그인해야 열리며, 화면은 저장 검증이 끝난 기록만 집계합니다. 숫자를 화면에서 고치지 않고, 기록이 바뀌면 5분 안에 다시 만들어집니다.

## 로그인

![검토 흐름 노선과 Google 로그인 패널](/images/edi-verification/review-login.webp)

원본 대조 → 판정 → 저장 검증 → 집계로 이어지는 검토 흐름을 노선으로 보여 주고, 마지막 역인 집계에서 로그인합니다. 허용 목록에 없는 계정은 들어갈 수 없습니다.

## 병원 현황

![병원 현황 표. 병원명과 코드는 가렸습니다](/images/edi-verification/review-table.webp)

- **위쪽 요약 숫자**: 검토 완료 병원, 승인, 보류, 승인불가, 미비점 있는 승인. 각 칸 아래 색 띠가 판정 색입니다(승인 초록, 보류 주황, 승인불가 빨강).
- **병원 표**: 병원명·코드 검색, 판정 칩, 문제 유형 선택, 열 머리글 정렬을 지원합니다. 기본 정렬은 보류 → 승인불가 → 승인이라 처리할 예외가 맨 위에 옵니다.
- **첨부 진행**: 병원의 첨부 페이지를 역 점으로 잇고, 점 색이 그 페이지의 판정입니다.
- **행 펼치기**: 처방월·첨부 페이지별 품목 수량 대조, 저장된 비고, 원본 검토·저장 기록, 근거 사진을 봅니다. 근거 사진은 로그인한 허용 계정에만 내려갑니다.
- 승인불가 병원은 목록에서 지우지 않고 취소선으로 남깁니다.

## 문제점 비율

![승인 자료의 문제점 비율 화면(공개용 출력)](/images/edi-verification/review-issues.webp)

승인 완료 병원을 분모로 도장 없음, 병원명 없음 같은 자료 미비점의 비율을 보여 줍니다. 한 병원에 문제가 여러 개면 각 항목에 중복 집계됩니다. 아래 비고 분류는 병원·처방월 단위 건수이며, 항목을 누르면 병원 현황 표가 그 유형으로 걸러집니다.

## 검토 단계

![검토 단계 안내](/images/edi-verification/review-guide.webp)

이번 검토의 세 단계(원본 대조, 승인 또는 확인대기, 저장 검증·기록)와 이 문서의 [EDI 검증](/edi-verification) 시스템이 공개한 흐름을 나눠 설명합니다.

## 휴대폰

![휴대폰 폭 병원 현황](/images/edi-verification/review-mobile.webp)

휴대폰에서는 왼쪽 메뉴가 위쪽 가로 노선으로 바뀌고, 요약 숫자를 먼저 본 뒤 표의 판정과 사유를 확인합니다.

## 공개용 출력

생성기를 `--public`으로 돌리면 병원 상세를 뺀 집계와 문제점 비율만 담은 화면을 만듭니다. 위 문제점 비율 캡처가 그 출력입니다.
