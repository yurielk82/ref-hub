# EDI 검토

CSO(영업대행사)가 실적 근거로 제출한 EDI 처방자료를 원본과 대조해 승인 여부를 정하는 업무와, 그 업무를 돕는 검토 도구를 설명합니다. 검토와 최종 확정은 외부 CSO 정산 플랫폼인 프로엠알(proMR)에서 합니다. 이 도구는 검토 기준과 판단 이력을 관리하고, 확정 기준을 적용한 AI 판정안을 만들어 저장한 뒤, 저장이 확인된 기록만 모아 보여 줍니다.

오너(영업관리 담당)와 허용된 Google 계정 소수가 매달 그달의 검토 진행 상황과 예외 건을 점검하는 데 씁니다.

EDI 검토는 여섯 단계로 돌아갑니다. CSO업체가 프로엠알에 EDI를 등록하면, 1차로 프로엠알 OCR이 제출 자료를 판독해 정산 제외 건을 나누고, 2차로 AI가 확정된 검증 기준으로 정산 대상 전 건을 대조하고, 3차로 담당자가 특이 건을 판단해 그 판단을 검증 기준에 반영합니다. 오류 건은 CSO업체별 안내 메일로 일괄 발송해 보완을 요청하고, 보완된 자료로 다음 회차 검토를 반복합니다. 이 절차로 EDI 검토 기간을 영업일 약 10일에서 약 5일로 줄일 것으로 예상하며, 이후 계산서 발행 등 후속 업무는 그대로 이어집니다. 단계별 설명은 [검증 단계와 기준 관리](/edi-verification/criteria)에 있습니다.

**현재 상태:** 운영 중입니다. 2026-11-16 검토 기록을 시작했고, 2026-11-18 기준 집계 서버와 5분 갱신이 동작합니다. 화면은 로그인 전용이라 이 매뉴얼에는 병원명을 가린 캡처만 싣습니다. 예전 CSO 정산 포털 안의 EDI 검토 모듈은 2026-09-29 포털과 함께 운영을 중지했습니다(아래 변경 이력).

## 용어

이 매뉴얼은 다음 말을 화면 라벨과 같은 뜻으로 씁니다.

| 용어 | 뜻 |
| --- | --- |
| EDI 처방자료 | CSO가 실적 근거로 프로엠알에 올린 병원 처방 자료 원본입니다. 종이 출력물, 프로그램 화면 사진, 팩스 같은 형태로 들어옵니다. |
| 흰색 행 | 프로엠알 처방 창에서 정산 대상인 행입니다. 분홍색 행은 시스템이 제외한 행이라 검토하지 않습니다. |
| 승인 · 승인대기 · 승인불가 | 프로엠알에 저장하는 행 단위 판정입니다. 집계 화면은 승인대기로 남긴 건을 **보류**로 표시합니다. |
| 검토 기준 | 오너가 확정한 판단 규칙입니다. 지금은 규칙 23개(버전 0.24, 2026-11-17)입니다. |
| 결정 이력 | 오너가 내린 판단과 정정을 시간순으로 쌓은 기록입니다. 기준을 바꿀 때 근거가 됩니다. |
| 검토한 달 | 저장 검증을 마친 날짜가 속한 달입니다. 집계 화면은 이 달 단위로 나뉩니다. |

## 주요 기능

이 도구가 하는 일은 다음과 같습니다.

- 검토 기준과 결정 이력을 파일로 관리하고 화면에서 보여 줍니다.
- 프로엠알의 승인대기 병원 목록을 받아 병원별 원본을 수집합니다.
- AI가 확정 기준을 적용해 흰색 행마다 판정안, 원본에서 읽은 수량, 고칠 수량, 비고, 근거를 냅니다.
- AI가 승인 또는 승인불가로 낸 행만 프로엠알에 저장하고, 다시 열어 실제로 바뀌었는지 확인합니다. 승인대기로 남긴 행은 저장하지 않고 사람에게 넘깁니다.
- 지급액예상이 있는 병원부터 여러 병원을 차례로 처리합니다(**연속 실행**).
- 저장이 확인된 기록만 모아 병원별 판정, 사유, 자료 미비 비율, 근거 사진을 보여 줍니다.
- 판정 목록과 AI 판정을 엑셀로 내려받습니다.
- 실제 검토 결과로 CSO업체별 보완 요청 안내 메일 예시를 만듭니다. 메일은 보내지 않으며, 일괄 발송 자동화는 준비 중입니다.

## 구성

검토 도구의 구성은 다음 표와 같습니다.

| 구분 | 내용 |
| --- | --- |
| 검토 대상 | 프로엠알(외부 CSO 정산 플랫폼) |
| 서버·화면 | Rust(axum) 서버, 생성기가 만드는 HTML·CSS·JS 화면 |
| 기록 | SQLite. 검토 기록(JSONL)을 가져와 담습니다. |
| AI 판정 | Claude API |
| 원본 수집·저장 | 서버가 오너 PC 브라우저를 원격으로 움직여 프로엠알을 읽고 저장합니다. |
| 로그인 | Google 로그인과 허용 계정 목록. 검토 실행은 실행 권한 계정만 합니다. |
| 갱신 | 5분마다 새 검토 기록을 받아 집계를 다시 만듭니다. |

## 변경 이력

이 매뉴얼은 처음에 CSO 정산 포털(csoweb) 안의 EDI 검토 모듈을 설명했습니다.

- **2026-03부터 2026-09까지:** CSO 정산 포털의 관리자 메뉴 **EDI 검토**에서 처방통계 ZIP·PDF를 올리면 방향 보정, OCR 추출, 자사 품목 대조를 거쳐 운영자가 판정하고 엑셀을 내려받았습니다. 프로엠알 도입 뒤 2026-09-29 포털 운영을 중지하면서 이 모듈도 쓰지 않습니다.
- **2026-11-16:** 프로엠알에서 검토하고, 검토 기준·결정 이력·검토 기록을 별도 저장소로 관리하기 시작했습니다.
- **2026-11-17:** 집계 화면, 검토 기준 화면, 엑셀 내려받기, AI 판정, 프로엠알 저장을 붙였습니다.
- **2026-11-18:** 연속 실행을 처음 운영에 썼고, 그때 나온 저장 오류를 고쳤습니다. 같은 날 검토 절차를 등록부터 보완 요청·반복까지 여섯 단계로 정리하고, 보완 요청 안내 메일 예시를 만들었습니다.

> 확인 기준: 2026-11-18, cso-edi-review 저장소(검토 업무·집계 화면)와 csoweb 저장소(옛 모듈) 기준.
