# 오류·경고 줄 고치기

화면 검증이 오류나 경고로 표시한 줄, 보고 사전점검에 걸린 줄을 찾아 고칩니다. 오류 줄은 그대로 보내면 KPIS가 반송하거나 보고가 보류됩니다.

## 시작 전에 필요한 것

- 날짜를 열 수 있는 승인된 계정([갑지·을지 고치기](/kpis-dsr-api/user-guide/data-editing))
- 고칠 줄이 미보고 또는 반송 상태일 것

## 오류 줄 찾아 고치기

1. 날짜를 열고 사이드바 **공급구분**에서 구분을 고릅니다.
2. 사이드바 아래쪽에서 **오류**와 **경고** 건수를 봅니다.
3. **오류**를 누릅니다. 첫 번째 오류 줄로 갑니다.
4. 줄의 표시된 칸에 마우스를 올려 메시지를 읽습니다.
5. 아래 표를 보고 칸을 고칩니다. 칸에서 벗어나면 저장되고 검증이 다시 돕니다.
6. 오류가 0이 될 때까지 3~5단계를 되풀이합니다. 경고도 같은 방법으로 확인합니다.

## 결과 확인

사이드바의 **오류**가 0이면 화면 검증을 통과한 것입니다. 경고는 보고를 막지 않지만 원인을 확인해 둡니다.

## 검증 규칙

### 필수값과 형식

| 칸 | 규칙 | 구분 |
| --- | --- | --- |
| 표준코드 | 13자리 숫자 | 오류 |
| 공급사업자등록번호 | 10자리 | 경고 |
| 공급받는자 사업자등록번호 | 10자리 | 경고 |
| 공급일자 | YYYYMMDD 8자리 | 오류 |
| 유효기한 | YYMMDD 6자리 | 오류 |
| 제조번호 | 20자리 이하 | 경고 |
| 공급수량 | 0보다 큼 | 오류 |
| 공급단가 | 0 이상 | 오류 |
| 공급자영업형태 | 1~7 | 오류 |
| 계약방법 | 1(수의계약) 또는 2(경쟁입찰) | 오류 |
| 공급형태 | 1~9 | 오류 |
| 일련번호구분 | 0, 1, 2 가운데 하나 | 오류 |

### 업무 규칙

| 규칙 | 구분 |
| --- | --- |
| 공급금액 = 공급수량 × 공급단가. 2원을 넘고 2%를 넘게 다르면 보고 사전점검이 보류합니다 | 오류 |
| 위 차이가 2% 이내이면 단가 끝수 차이로 보고 그대로 보냅니다 | 경고 |
| 폐기 보고는 공급단가·공급금액이 0원 | 오류 |
| 공급형태가 요양기관(5)이면 요양기관기호 8자리 | 오류 |
| 폐기·취소는 반송사유 기재 | 경고 |
| 일련번호 부착 품목(일련번호구분 1)은 을지가 있어야 함 | 오류 |
| 을지 연번 필수 | 오류 |

공급단가·공급금액은 부가세 포함 값입니다. 1~2원 반올림 차이는 그대로 보냅니다.

## 규격 오류 한꺼번에 고치기

공급규격(포장내총수량)이 표준코드 마스터와 다르면 KPIS가 FE로 반송합니다.

1. 위쪽 **도구** › **규격검증**을 누릅니다. 옆 숫자는 규격이 다른 줄 수입니다. 0이면 누를 수 없습니다.
2. 고칠 수 있는 줄의 규격·수량을 마스터에 맞춰 바로 저장하고, 고친 줄 수를 알림으로 보여 줍니다. 바뀐 수량이 정수가 아닌 줄은 고치지 않고 "검토 N건"으로 알립니다. 그 줄은 직접 확인해 고칩니다.

날짜를 열 때와 자동 보고 전에도 같은 규칙으로 미보고·반송 줄의 규격을 마스터에 맞춥니다.

## 보고 사전점검

보내기 직전에 서버가 한 번 더 점검합니다. 걸린 줄은 보내지 않고 **[사전점검]**으로 시작하는 사유를 남깁니다. **KPIS 보고** › **보고** 탭에서 "사전점검 오류 N줄"로 보입니다.

| 사전점검 사유 | 고치는 법 |
| --- | --- |
| 필수값 없음 | 표준코드, 포장내총수량, 공급수량, 공급일자, 공급금액, 공급단가를 채웁니다 |
| 일련번호 부착 품목인데 을지가 없음 | 그날 을지를 다시 받습니다 |
| 을지 일련번호 수가 공급수량과 다름 | 공급수량이나 을지를 원천과 맞춥니다 |
| 공급금액이 공급수량×공급단가와 다름 | 원천 금액을 확인해 고칩니다 |
| 정정·취소인데 원 출고 줄을 찾지 못함 | 정정·취소 줄을 다시 만듭니다 |
| 정정·취소 기한이 지남 | 반송신청으로 고칩니다 |
| 공급받은자 사업자번호 10자리 필요 | 사업자번호를 넣습니다. 폐기는 자사(자체폐기) 또는 폐기업체·보건소 번호입니다 |
| 요양기관기호 8자리 필요 | 요양기관기호를 넣습니다. 부여 전이면 99999999 |

## 주문 대조로 빠진 줄

보내기 전 주문 대조가 주문 내역과 맞출 수 없는 줄(주문에 없는 줄, 그날 주문 자료가 아직 없는 날, 같은 비율로 못 고치는 로트 줄)은 빼 두고 다음 보고 때 다시 견줍니다. 보고 계획 창에 "이번에 뺀 줄"로 보입니다. 표준코드가 틀려 빠진 줄은 **표준코드 정정 제안**으로 고칩니다([KPIS에 보고하기](/kpis-dsr-api/user-guide/pdf-export)).

## 잘 안 될 때

- 고쳤는데 오류가 남으면 같은 줄의 다른 칸 메시지를 봅니다. 한 줄에 여러 규칙이 걸릴 수 있습니다.
- 칸을 고칠 수 없으면 그 줄이 잠긴 상태인지 **보고상태**를 봅니다.
- 반복되는 오류는 규칙으로 자동 보정할 수 있습니다([규칙·코드매핑 관리하기](/kpis-dsr-api/user-guide/rule-management)).
