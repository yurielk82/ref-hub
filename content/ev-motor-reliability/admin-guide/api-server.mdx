# API 서버

이 쪽은 Python API의 구조, 경로, 인증, 사용량 제한을 정리한 참고 자료입니다. 웹 화면의 시뮬레이션·분석·실측 데이터·AVL 변환이 모두 이 API를 부릅니다.

## 코드 구조

API는 `api/` 아래 네 층으로 나뉩니다. 계산은 `simulation/`과 `analysis/`의 순수 계산 코드를 불러 씁니다.

| 층 | 폴더 | 하는 일 |
|----|------|---------|
| 표현 | `api/presentation/` | 경로별 라우터, 요청 검사 |
| 응용 | `api/application/` | 시뮬레이션·분석·보고서·채팅 서비스 |
| 도메인 | `api/domain/` | 요청·응답 스키마(pydantic), 오류 종류 |
| 인프라 | `api/infrastructure/` | DB, 인증, 사용량 제한, WebSocket, AVL 변환기 연결, 로그 |

진입점은 `api/main.py`의 `app`이고, 모든 경로는 `/api/v1` 아래에 있습니다. API 문서는 `/docs`에서 봅니다.

## 경로

| 경로 | 하는 일 |
|------|---------|
| `/health` | Python, 데이터베이스, Git, 하드웨어 연결 상태 |
| `/simulation`, `/optimization` | 단일·배치·스윕 시뮬레이션, PID·FOC·Ziegler-Nichols 게인 탐색 |
| `/analysis` | Weibull, FMEA, 시뮬 vs 실측 비교 |
| `/analysis/sample-data` | 실측 엑셀 업로드·목록·상세·삭제 |
| `/reports` | HTML 보고서 생성·다운로드, PDF 보고서 생성 |
| `/ws` | 모니터 화면용 실시간 데이터 WebSocket |
| `/hardware` | 시리얼 수집 시작·중지, 긴급 정지 |
| `/chat`, `/chat/history`, `/claude` | AI 채팅(Anthropic API), Claude Code CLI 에이전트 모드, 대화 기록 |
| `/history` | 시뮬레이션 실행 기록 |
| `/files`, `/git` | 코드 화면의 파일 읽기·쓰기, Git 브랜치·상태·끌어오기·커밋 |
| `/admin` | 관리 화면의 함수 목록, 패키지, 시스템 상태, 로그 |
| `/avl-converter` | AVL 변환 세션, 파일 업로드, 미리보기, 변환, 다운로드 |

## 인증과 권한

웹 화면 로그인은 Neon Auth가 맡고, API는 요청에 실린 JWT를 Neon Auth 공개키(JWKS)로 검증합니다. 서명 방식은 `EVMOTOR_AUTH_ALGORITHM`으로 정합니다. 검증한 사용자 정보는 `users` 표에 맞춰 둡니다.

- 인증 검사는 `EVMOTOR_AUTH_ENABLED`로 켜고 끕니다. 운영에서는 켜 둡니다.
- 토큰 검증 실패만으로 요청을 막지는 않습니다. 관리 기능처럼 권한이 필요한 경로가 각자 사용자와 역할을 확인합니다.
- `/health`와 API 문서 경로는 토큰 없이 엽니다.
- AVL 변환 경로는 로그인 없이 씁니다. 웹 화면도 `/avl-converter`를 로그인 검사에서 뺍니다.

사용자 역할은 `admin`, `member`, `user` 셋입니다. 처음 로그인한 사용자는 승인 대기 상태가 되고, 관리자가 **사용자 관리**에서 승인하면 `member`가 됩니다.

## 사용량 제한

같은 접속 주소에서 오는 요청 수를 분 단위로 제한합니다. 기본값은 다음과 같고 `EVMOTOR_RATE_LIMIT_*` 환경 변수로 바꿉니다.

| 구분 | 기본 제한 |
|------|-----------|
| 기본 | 분당 60회 |
| 시뮬레이션 | 분당 10회 |
| 최적화 | 분당 5회 |
| 보고서 | 분당 20회 |
| 채팅 | 분당 20회 |
| 파일, 하드웨어 | 분당 30회 |
| 실측 엑셀 업로드 | 분당 10회 |

제한을 넘으면 `429`와 `RATE_LIMIT_EXCEEDED`를 돌려줍니다.

## 파일 크기와 보관

| 대상 | 제한·보관 |
|------|-----------|
| 실측 엑셀 업로드 | `.xlsx`만, 50MB 이하. 원본 파일은 서버에, 분석 결과는 DB에 저장 |
| AVL 변환 업로드 | 파일당 50MB 이하. **Target Steps** 최대 1,000,000 |
| AVL 변환 세션 | 서버 임시 폴더에 세션별 폴더를 만들고 1시간 뒤 지움 |
| 보고서 | `report_연월일_시분초.html` |
| 동시 WebSocket 연결 | 기본 10개(`EVMOTOR_WS_MAX_CONNECTIONS`) |

DB 연결이 없어도 시뮬레이션과 분석은 동작합니다. 이때는 기록 저장과 조회만 `503`과 `DB_UNAVAILABLE`로 실패합니다.

## 로그

로그는 한국 표준시로 시간을 찍습니다. 관리자는 웹의 **관리** 화면 **로그** 탭에서 **전체**, **INFO**, **WARNING**, **ERROR**로 걸러 봅니다.
