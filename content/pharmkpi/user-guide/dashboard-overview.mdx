# 종합 현황과 월간 KPI 보기

한 달 실적을 **KPI** 메뉴에서 확인합니다. **종합 현황**으로 대표 지표를 훑고, **월간 KPI**로 보고 양식 그대로의 본표를 보고, **데이터 대조**로 숫자가 원본과 맞는지 확인합니다.

## 시작 전에 필요한 것

- **KPI** 메뉴 권한. 영업본부는 같은 **월간 KPI** 화면을 **영업본부** 메뉴에서도 엽니다.
- 볼 기준월. 판매·수금 마감이 끝난 달만 공식 숫자가 나옵니다.

## 종합 현황으로 대표 지표 보기

1. 왼쪽 레일에서 **KPI**를 누릅니다. 첫 화면이 **종합 현황**입니다.
2. **기준월**에서 볼 달을 고릅니다.
3. 위쪽 **공식 대표 지표** 카드를 읽습니다. 카드마다 있는 안내 단추에 그 숫자의 기준이 적혀 있습니다.
4. 매출을 더 보려면 **매출 합계** 카드를 눌러 **매출 개요**로 갑니다. 같은 달의 본표를 보려면 **월간 KPI 원표**를 누릅니다.

카드는 여섯 장입니다.

| 카드 | 뜻 |
| --- | --- |
| **매출 합계** | 기준월 매출 |
| **수금** | 기준월 수금액 |
| **채권 잔고** | 기준월 말 채권 잔고 |
| **전체 할인율** | 기준월 할인율 |
| **총재고 개월** | 유통재고와 창고재고를 합친 재고가 직전 3개월 월평균 매출의 몇 달 치인지. 유통재고 자료가 아직 들어오지 않아 지금은 빈칸으로 보입니다 |
| **반품률** | 기준월 반품 비율 |

카드 아래 줄에는 목표 대비 또는 전년 동월 대비 증감이 붙습니다. 잔고처럼 월말 값은 전년 동월말과 비교합니다. 금액은 억원입니다. 카드 숫자는 **월간 KPI**와 같은 원본 자료의 당월 실적입니다. 원본 자료가 다시 갱신되면 값도 바뀔 수 있습니다.

카드 아래 **전사 매출** 구간은 월 마감 때 보존한 매출 발행본으로 그립니다. **당월**, **분기 누계**, **당년 누계** 가운데 하나를 고르고, 월별 추세를 전년과 겹쳐 보고, 사업별 나눔을 봅니다. 더 들어가려면 아래 링크를 씁니다.

- **구성·범위 설정**: 채널·품목·팀별 구성을 고릅니다.
- **증감 기여·거래**: 전년보다 늘고 준 원인을 거래 단위까지 봅니다.
- **매출 잇기**: 전년 매출에서 올해 매출까지 항목별로 이어 봅니다.

## 지표별 화면 보기

메뉴 목록의 **매출**·**수금**·**채권**·**할인율**·**재고**·**반품** 묶음에는 같은 순서의 화면이 있습니다.

| 화면 성격 | 매출 묶음의 예 | 보는 것 |
| --- | --- | --- |
| 개요 | **매출 개요** | 기준월 실적과 추세 |
| 구성 | **매출 구성** | 채널·팀·품목·거래처별 나눔 |
| 비교 | **매출 목표·기간 비교** | 목표 대비, 전년·전월 대비 |
| 원인 | **매출 증감 원인·상세** | 늘고 준 항목과 그 거래 |

채권 묶음에는 **채권연령·거래처**, 재고 묶음에는 **LOT·사용기한 확인**처럼 그 지표에만 있는 화면이 더 있습니다. 매출 원인을 따라가는 순서는 [매출 증감 원인 찾기](/pharmkpi/user-guide/sales-analysis)에 있습니다.

## 월간 KPI 본표 보기

**월간 KPI**는 회사가 제출하는 월간 KPI 엑셀 양식(요약과 본표)을 원천 자료로 채운 화면입니다.

1. 메뉴 목록의 **종합** 묶음에서 **월간 KPI**를 누릅니다.
2. **기준월**을 고릅니다.
3. **매출목표 대비 실적**, **월별 본표**, **채권 · 할인율 · 재고 · 반품** 표를 차례로 읽습니다. 휴대폰에서는 **표 고르기**로 표를 하나씩 엽니다.
4. 표 위 **데이터 기준**의 안내 단추로 자료 기준 시각을 확인합니다.
5. 엑셀이 필요하면 **내보내기**에서 **엑셀(XLSX)** 을 고릅니다.

표 머리의 Plan·Actual·%Plan·%YoY 같은 영어 용어는 원본 KPI 엑셀 양식의 말을 그대로 씁니다.

본표 금액은 백만원 정수, 요약 카드는 억원 소수 한 자리입니다. 비율은 소수 두 자리, 재고 개월은 소수 한 자리입니다. 복사·엑셀로 꺼낸 값은 원 단위 정수입니다.

진행 중인 달은 **진행 중인 달**로 표시합니다. 유통재고 칸은 외부 자료가 들어오지 않아 빈칸이며, 빈칸 옆 설명 단추에 이유가 있습니다.

## 데이터 대조로 숫자 확인하기

**데이터 대조**는 보고서 기준값과 상세 원본 자료, 팀·사원 목표 합계를 나란히 놓고 맞는지 보입니다.

1. 메뉴 목록의 **검증** 묶음에서 **데이터 대조**를 누릅니다.
2. **기준월**을 고릅니다.
3. 지표별·월별 대조 상태를 보고, 일치하지 않는 달을 찾습니다.

![데이터 대조 화면](/assets/selected-portfolio/images/pharmkpi/verification-content-6c6ad2a37e5a.webp)

지표별·월별로 원본 자료와 집계 값의 대조 상태를 표시해 확인이 필요한 달을 구분합니다.

대조는 매일 새벽 자동 검증에서도 돕니다. 새벽 검증을 아직 돌지 않은 기준월은 **BI 대조 미검증**으로 표시됩니다.

## 결과 확인

기준월 카드에 숫자가 채워지고, **월간 KPI** 표가 열리면 끝입니다. 숫자 대신 안내 문구가 보이면 아래를 봅니다.

## 잘 안 될 때

- **KPI 본표 발행 대기**: 그 달 실적 발행본이 아직 없습니다. 마감·발행이 끝난 뒤 새로고침합니다.
- **지표 재계산 미완료**: 자동 재시도가 끝난 뒤 새로고침합니다. 오래 계속되면 관리자가 **월간 KPI**의 **BI에서 갱신**으로 다시 계산합니다.
- **선택할 수 없는 기준월입니다**: 고를 수 있는 범위 밖의 달입니다. 다른 기준월을 고릅니다.

더 많은 경우는 [문제 해결](/pharmkpi/admin-guide/troubleshooting)에 있습니다.
