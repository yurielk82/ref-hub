# 의약품 공급내역보고 업무 자동화

엑셀로 수작업하던 공급내역보고를 단계적으로 자동화하고, ERP 전환 후에도 보고 업무를 이어갈 수 있도록 구축한 업무용 웹 시스템입니다.

## 두 차례의 업무 개선

### 최초 개선: 엑셀 수작업에서 웹 시스템으로

입사 당시 엑셀로 수작업하던 공급내역보고를 엑셀 자동화로 개선하고, 이후 웹 기반 시스템으로 발전시켰습니다. 반복되는 자료 검증·보정 작업을 자동화했습니다.

### ERP 전환 후 대응: 업무 유지와 API 연계

이후 ERP와 공급내역보고 프로그램이 함께 변경됐으나 새 보고 프로그램의 오류가 3개월 이상 지속됐습니다. 자체 구축한 웹 시스템으로 보고 업무를 이어갔으며, 이후 보고 API를 연계한 시스템을 구축했습니다.

API 연계 기능은 구축했으며, 실제 운영 전송 검증은 별도 확인이 필요한 상태입니다.

## 업무 처리 흐름

**물류 마감 → 바코드 서버 접속 및 갑지·을지 다운로드 → API 공급내역보고 → 다음 날 아침 의약품 공급내역보고 오류·특이사항 확인**

| 단계 | 처리 내용 |
| --- | --- |
| 물류 마감 | 물류 마감에 맞춰 보고 자료 수집을 진행 |
| 자료 확보 | 바코드 서버에 접속해 갑지·을지 다운로드 |
| 공급내역보고 | 자료를 검증·보정하고 보고 API로 제출·결과 확인 |
| 아침 확인 | 다음 날 아침 전날 의약품 공급내역보고의 오류와 특이사항 확인 |

보고 전 자료 검증·보정 결과를 검토하고, API 제출 후에는 처리 결과를 확인합니다. 다음 날 아침 오류와 특이사항을 다시 점검합니다.

## 자료 검증과 보고

- 갑지는 공급내역 자료이며, 을지는 갑지와 연결되는 일련번호 자료입니다.
- 표준코드·규격·수량·단가 등을 검증하고 필요한 항목을 보정합니다.
- 파일 내보내기 후 포털에서 보고하는 방식과 API 연계 보고를 구분합니다.
- API 제출과 처리 결과 확인은 별도 단계이며 결과 미확인·반송·보류 상태도 확인해야 합니다.
