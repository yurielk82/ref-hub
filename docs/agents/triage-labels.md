# 분류 라벨

Matt 스킬은 다섯 가지 분류 역할로 말한다. 이 표가 역할을 이 저장소의 실제 글자(GitHub 라벨)로 잇는다(기본값 그대로, 2026-10-20).

| Matt 역할         | 이 저장소 라벨    | 뜻                              |
| ----------------- | ----------------- | ------------------------------- |
| `needs-triage`    | `needs-triage`    | 관리자가 판단해야 함            |
| `needs-info`      | `needs-info`      | 보고자에게 정보를 기다림        |
| `ready-for-agent` | `ready-for-agent` | 명세 완료, 에이전트가 맡아도 됨 |
| `ready-for-human` | `ready-for-human` | 사람이 구현해야 함              |
| `wontfix`         | `wontfix`         | 하지 않음                       |

스킬이 역할을 말하면(예: "에이전트 준비 라벨을 붙여라") 이 표의 라벨을 쓴다.
