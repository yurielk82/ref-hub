# 시장·경쟁 자료 보기

심평원·식약처 공공 데이터와 자사 판매 자료를 함께 놓고 성분 시장의 크기와 성장, 경쟁 제품, 자사 위치를 봅니다. 공공 데이터는 매일 아침 자동으로 모입니다.

## 시작 전에 필요한 것

- **시장** 메뉴 권한.
- 볼 품목이나 성분 이름, 또는 기간.

## 어떤 화면을 열까

**시장** 메뉴의 **시장·경쟁** 묶음과 **지역** 묶음에 아래 화면이 있습니다.

| 화면 | 보는 것 | 자료 |
| --- | --- | --- |
| **시장 포트폴리오** | 자사 허가 품목, 평균 상한가, 전문·일반 구성, 품목별 가격 | 식약처·심평원 |
| **처방 동향** | 성분 시장 규모, 최근 12개월 누적(MAT), 성장, 적응증, 자사 위치 | 심평원 의약품 사용 정보 |
| **대조약·경쟁제품** | 자사 품목의 대조약과 같은 성분 경쟁 제품 | 식약처·심평원 |
| **주력품목 시장** | 회사가 정한 주력 품목 8개의 성분 시장과 자사 도매 매출, 질병별 사용 | 심평원 + 자사 판매 |
| **전국 시장** | 전국 성분·ATC 분류별 순위와 추이, 상병별 사용 | 심평원 |
| **생산실적**, **생산실적 조회** | 품목별 생산실적과 그 검색 | 식약처 |
| **원료의약품(DMF) 조회** | 등록된 원료의약품 | 식약처 |
| **판매 지도** | 지역별 자사 판매 | 자사 판매 |

![시장 포트폴리오 화면](/assets/selected-portfolio/images/market-analysis/portfolio-content-9249e36b4422.webp)

시장 포트폴리오는 허가 품목·평균 상한가·전문·일반 구성과 품목별 가격을 한 화면에서 비교합니다.

## 성분 시장 흐름 보기

1. **시장** 메뉴에서 **처방 동향**을 엽니다.
2. 위쪽 기간 칸에서 시작 달과 끝 달을 고릅니다. 자주 쓰는 기간은 **기간 바로가기**로 고릅니다. 자료가 다 모인 달만 고를 수 있습니다.
3. **약효군**을 골라 볼 시장을 정합니다.
4. **시장 개요**에서 시장 규모와 최근 12개월 누적(MAT), 올해와 작년 같은 달 비교를 봅니다.
5. **자사 포지션**과 **성장 기여도**에서 자사가 시장 안에서 어디에 있는지 봅니다.

마지막으로 고른 기간은 계정마다 기억합니다. 주소에 기간이 있으면 주소가 먼저입니다.

## 경쟁 제품 확인하기

1. **대조약·경쟁제품**을 엽니다.
2. **자사 제품 행렬**에서 볼 자사 품목을 고릅니다.
3. **대조약 대비 가격**에서 대조약과 상한가를 비교합니다.
4. **직접 경쟁 제품**과 **성분 시장**에서 같은 성분의 경쟁 제품과 점유·성장을 봅니다.
5. **지역별 매출**과 **지역 기회 근거**에서 자사 판매가 약한 지역을 찾습니다.

## 지역별 판매 보기

1. **지역** 묶음에서 **판매 지도**를 엽니다.
2. 기간을 고릅니다. 처음에는 지난달 한 달입니다.
3. **색칠**에서 지도에 칠할 값을 고릅니다.
4. **최고 매출 지역**과 **지역별 상위 거래처**, **지역별 채널 구성**을 봅니다.

이번 달은 진행 중이라 기본 기간에서 빠지고, 고르면 **진행 중**으로 표시됩니다.

## 결과 확인

고른 기간·성분의 차트와 표가 채워지면 끝입니다.

## 잘 안 될 때

- 최근 달을 고를 수 없으면 그 달 공공 자료가 아직 다 모이지 않은 것입니다. 다 모인 달까지만 고를 수 있습니다.
- 숫자가 오래돼 보이면 관리자가 **원본 자료** 메뉴의 **공공 API 수집 현황**에서 마지막 수집을 확인합니다.

다른 경우는 [문제 해결](/pharmkpi/admin-guide/troubleshooting)을 봅니다.
