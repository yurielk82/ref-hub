# CSO 정산 포털

CSO 정산 포털은 제약사가 위탁영업 업체(CSO, Contract Sales Organization)에 정산 내역을 알려 주던 웹 포털입니다. 영업관리팀이 SIT 솔루션에서 내보낸 정산 엑셀을 올리면, 회원사로 가입한 CSO가 사업자번호로 로그인해 자기 몫의 정산 내역을 보고 내려받았습니다. 관리자는 같은 포털에서 회원 승인, 업체 표기 연결, 업체별 안내 메일 발송을 처리했습니다.

## 현재 상태

**운영 종료.** 2026-09-29에 정산 업무를 외부 정산 시스템(프로엠알)으로 옮겼습니다.

- 그 뒤로 이 포털에는 새 정산 자료를 올리지 않습니다.
- 마지막으로 정산 자료가 올라간 달은 2026-06 정산월입니다(2026-06-30 업로드). 그 뒤로 새 정산 자료는 없습니다.
- 운영 중지 뒤 화면 코드는 바뀌지 않았습니다. 그 뒤 커밋은 의존성과 문서 정리뿐입니다. 그래서 이 매뉴얼의 화면 설명은 운영 당시 화면과 같습니다.

근거는 저장소 `AGENTS.md`의 운영 상태 항목, 커밋 기록, 2026-11-18 운영 데이터베이스 읽기 조회입니다.

## 누가 무엇에 썼나

| 사용자 | 한 일 |
|------|------|
| 회원사(CSO 담당자) | 가입 신청, 월별 정산서 조회와 엑셀 다운로드, 월별 합계·품목 기준·공지 확인, 회원 정보 변경 요청 |
| 관리자(영업관리팀) | 정산서 업로드, 가입 승인, CSO 매칭, 메일머지 발송, 공지 관리, 정산서·EDI 검토 |

## 주요 기능

- 사업자번호로 가입하고 로그인합니다. 가입할 때 국세청 사업자 상태를 바로 확인해 계속사업자만 받습니다.
- 회원사는 CSO 매칭으로 이어진 자기 정산 자료만 봅니다. 관리자는 회원사가 볼 수 있는 가장 이른 달을 정합니다.
- 정산 엑셀을 열 이름 짝짓기 확인 뒤 올립니다. 같은 달을 다시 올리면 그 달 자료가 통째로 바뀝니다.
- 메일머지로 회원사마다 그 업체의 합계와 정산 표를 넣은 안내 메일을 보냅니다. SMTP 발송은 대기열과 별도 워커가 차례로 처리합니다.
- 관리자 대시보드에서 접속률, 할 일, 월별 추이와 상위 업체·제품 통계를 봅니다.
- EDI 검토로 처방통계 이미지·PDF를 OCR(문자 인식)로 읽어 정산서 수량과 비교합니다.

EDI 검토는 거래처가 낸 처방통계 원본을 OCR로 읽고, 정산서의 품목·수량과 줄 단위로 맞춰 검수자가 판정하는 기능입니다. 이 포털의 관리자 메뉴 **정산 관리**의 **EDI 검토**로 들어갔습니다. 화면과 절차는 [EDI 검증 매뉴얼](/edi-verification)에 따로 정리되어 있습니다.

## 구성

| 영역 | 사용 기술 |
|------|------|
| 화면·서버 | Next.js 16(App Router), React 19, TypeScript, Tailwind CSS, Radix UI |
| 데이터 | 워크스페이스 공용 Supabase(셀프호스팅, PostgreSQL 17.6) |
| 인증 | 자체 JWT(`jose`)와 bcrypt. Supabase Auth는 쓰지 않음 |
| 메일 | Resend(시스템 메일), SMTP(대기열과 이메일 워커) |
| OCR | OpenAI·Anthropic API, Sharp(이미지 처리), Redis(캐시) |
| 실행 | 자체 서버의 Next.js 단독 실행 빌드와 워커 두 개(systemd) |
| 오류 추적 | Sentry |

마지막 판은 `v1.59.26`입니다. 구성과 배포 순서는 [실행 구성과 배포](/csoweb/admin-guide/deployment)에 있습니다.
