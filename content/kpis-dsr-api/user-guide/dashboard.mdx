# 매일 보고 상태 확인하기

아침마다 전날까지의 공급내역이 KPIS에 제대로 보고됐는지 확인하고, 사람이 볼 날을 찾습니다. 보고 자체는 자동 보고가 하므로 평소에는 이 확인만 하면 됩니다.

## 시작 전에 필요한 것

- 승인된 계정
- 직접 보고하거나 결과를 정리하려면 관리자 계정

## 확인 순서

1. 사이드바에서 **대시보드**를 누릅니다. **공급내역 현황판**이 열립니다.
2. 오른쪽 위에서 **월별**을 고르고, 달 선택으로 확인할 달을 맞춥니다. 아래 카드는 모두 이 달을 따릅니다.
3. 맨 위 **적기보고율** 줄에서 **자사 적기보고율**과 **타사 적기보고율**이 목표 95% 이상인지 봅니다. **목표 미달**이면 이 쪽 아래 "적기보고율이 목표 아래일 때"를 봅니다.
4. **할 일**(날짜별 공급내역 보고)에서 어제 날짜 카드의 큰 글자를 읽습니다. **보고 완료**와 **API 접수 확인**이면 그날은 끝입니다.
5. 다른 상태이면 아래 "날짜 상태와 할 일" 표에 따라 처리합니다.
6. **반송·반송신청** 줄이 보이면 **반송 처리**를 눌러 반송 줄을 봅니다([반송 줄 고쳐 다시 보고하기](/kpis-dsr-api/user-guide/return-management)).
7. **주문·바코드·KPIS 날짜별 대조**에서 **다른 날만**을 켜고 다른 날이 있는지 봅니다([주문·KPIS 대조 확인하기](/kpis-dsr-api/user-guide/order-check)).
8. 사이드바 **KPIS 보고**에서 **로그** 탭을 열고 **확인·오류만**을 켭니다. 자동 보고·물류 마감·판매 마감 뒤 검사가 남긴 보류와 오류를 읽습니다.

## 결과 확인

할 일의 평일 카드가 모두 **보고 완료**, **보고 대상 없음**, 휴일 중 하나이고 로그에 새 오류가 없으면 확인이 끝납니다.

## 날짜 상태와 할 일

카드의 큰 글자는 보고 상태, 작은 글자는 그 까닭입니다. 위에 있는 상태일수록 먼저 처리합니다.

| 큰 글자 · 작은 글자 | 뜻 | 할 일 |
| --- | --- | --- |
| 결과 확인 필요 · API 응답 미확인 | 보냈지만 KPIS에 닿았는지 모르는 줄이 있습니다 | 카드의 **API 결과 확인**을 누릅니다. 풀리지 않으면 [KPIS에 보고하기](/kpis-dsr-api/user-guide/pdf-export)의 결과 미확인 정리 |
| 변경 확인 필요 · API 접수 후 자료 변경 | 접수된 뒤 원천이나 적재본이 바뀌었습니다 | `⋯` 메뉴의 **변경 내용 확인** |
| 변경 확인 필요 · 수기보고 자료 변경 | 포털로 낸 뒤 자료가 바뀌었습니다 | `⋯` 메뉴의 **변경 내용 확인** |
| 변경 확인 필요 · 변경 내용 대조 | 원천과 적재본이 달라 대조가 필요합니다 | `⋯` 메뉴의 **변경 내용 확인** |
| 조회 중 · 바코드 원천 대조 | 원천을 읽는 중입니다 | 기다립니다 |
| 보고 중 · API 결과 대기 | 보고가 진행 중입니다 | 기다립니다. 창을 닫아도 서버가 계속합니다 |
| 일부 미보고 · 반송 내용 확인 | 반송된 줄이 있습니다 | [반송 줄 고쳐 다시 보고하기](/kpis-dsr-api/user-guide/return-management) |
| 자료 확인 필요 · 최근 수집 실패 | 원천을 읽지 못해 자료가 없습니다 | [문제 해결](/kpis-dsr-api/admin-guide/troubleshooting)에서 바코드 서버 연결을 확인한 뒤 `⋯` 메뉴의 **데이터 받아오기** |
| 일부 미보고 · API 일부 접수 | 일부 줄만 접수됐습니다 | **KPIS 보고**에서 그날을 열어 미보고 줄을 봅니다 |
| 완료 확인 전 · 엑셀 다운로드 | 엑셀만 내려받았고 제출 완료 표시가 없습니다 | 포털 제출을 마쳤으면 `⋯` 메뉴의 **수기보고 완료로 표시** |
| 확인 필요 · 최근 작업 실패 | 최근 작업이 실패했습니다 | **KPIS 보고** › **로그**에서 실패 사유를 봅니다 |
| 보고 전 | 실린 자료가 있고 아직 보내지 않았습니다 | 자동 보고를 기다리거나 카드의 **API 보고**로 직접 보냅니다 |
| 보고 완료 · 수기 완료 표시 | 사용자가 포털 제출 완료로 표시했습니다 | 없음 |
| 보고 완료 · API 접수 확인 | 모든 줄이 API로 접수됐습니다 | 없음 |
| 보고 대상 없음 | 그날 실린 갑지가 없습니다 | 없음. 갑지가 없는 날은 공급이 없는 날입니다 |

> **참고:** 엑셀 다운로드와 수기보고 완료 표시는 KPIS 접수를 증명하지 않습니다. 접수 여부는 API 접수 확인이나 업무포털에서 봅니다.

## 할 일 화면 쓰는 법

- **주간**은 월~금 5일을 한 줄로, **월 달력**은 그달 평일을 달력으로 보여 줍니다.
- 이전·다음 기간 버튼, **날짜 선택**, **이번 주**로 옮겨 다닙니다. 오늘 날짜는 테두리로 표시합니다.
- 토·일은 카드로 보이지 않지만 주말 공급 자료도 보고 대상에 들어갑니다.
- 공휴일과 회사 휴무는 붉은 글자로 표시합니다. 휴일에 실린 공급 자료가 있으면 보고 대상으로 남습니다.
- 카드 오른쪽 `⋯` 메뉴에는 그날 갑지 건수, **변경 내용 확인**, **API 결과 다시 확인**, **보고 상세 열기**, 공급구분별 **엑셀 다운로드**, **데이터 받아오기**, **휴일 관리에서 휴무 변경**이 있습니다. 수기보고 완료 표시와 해제는 엑셀을 내려받은 날에만 보이고 관리자만 씁니다.
- 여러 날을 한꺼번에 보내려면 **일괄 보고 검토**를 누릅니다([KPIS에 보고하기](/kpis-dsr-api/user-guide/pdf-export)).

## 그 밖의 카드

- **공급 현황:** 출고금액·반품금액·순매출(출고 − 반품)을 일·월·연 단위로 봅니다. **그래프**, **표**, **둘 다** 가운데 고릅니다. 자료가 없거나 아직 오지 않은 기간은 0으로 표시하지 않습니다.
- **주문·바코드·KPIS 날짜별 대조:** 날짜·공급구분마다 주문 금액, 바코드 줄·수량·금액, KPIS 건·수량·금액을 놓고 **주문=바코드**, **바코드=KPIS**, **KPIS=주문** 일치 여부와 **왜 다른가**를 보여 줍니다. 오늘은 KPIS 집계가 확정 전이라 어제까지만 견줍니다.
- **참고 › KPIS 정보:** **표준코드 마스터 갱신(MA118)**으로 심평원 표준코드를 받아 우리 마스터를 고치고, **입고내역 (MA115)**에서 우리에게 들어온 공급내역을 조회합니다.
- **연도별** 탭은 여러 해의 보고 지표를 비교합니다.

## 적기보고율이 목표 아래일 때

적기보고율은 기한 안 보고수량을 분기 공급수량으로 나눈 값입니다. 심평원 집계로 계산하며 엑셀 다운로드나 수기 완료 표시로 계산하지 않습니다. 목표 아래로 내려가면 자동으로 **로그**에 남습니다. 늦은 보고가 생긴 날과 반송 줄을 먼저 확인합니다. 기한(공급월 다음 달 말일)이 지난 줄을 고칠 때는 새 줄로 보내지 않고 반송신청 뒤 업무포털 **반송보고**로 고칩니다. 새 줄로 보내면 늦은 보고로 잡혀 적기보고율이 더 떨어집니다.

## 잘 안 될 때

- 카드가 비어 있거나 **날짜 현황 조회 중**에서 멈추면 **다시 조회**를 누릅니다.
- **적기보고율**에 **설정 필요**가 보이면 관리자가 **KPIS 연동 키**의 보고 설정(클라이언트 아이디·시크릿, 보고 사업자번호)을 확인합니다.
- 그 밖은 [문제 해결](/kpis-dsr-api/admin-guide/troubleshooting)을 봅니다.
