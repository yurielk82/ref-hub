# 공급 자료 가져오기

바코드 서버에서 공급내역(갑지·을지)을 다시 받거나, 원천이 바뀐 날을 다시 싣거나, 엑셀 파일을 올립니다. 평소에는 물류 마감 뒤 자동으로 실리므로 자동 적재가 실패했을 때나 특정 날을 직접 다룰 때만 씁니다.

## 시작 전에 필요한 것

- 관리자 계정. 다시 싣기와 새 줄 덧붙이기는 관리자만 합니다.
- 바코드 서버 연결이 정상이어야 합니다. 연결 상태는 **KPIS 보고** › **로그** 위쪽의 바코드 원천 표시로 봅니다.

## 자동 적재가 하는 일

KPI.가 물류 마감을 알리면 적재기가 마감일과 앞 14일을 바코드 원천과 대조해 달라진 날만 다시 싣습니다. 물류 마감이 없는 날도 밤 11시에 오늘 날짜를 싣습니다. 사람이 고쳤거나 보고한 날은 덮지 않고, 원천이 바뀌었으면 그날을 **변경 확인 필요**로 남깁니다. 원천을 읽지 못하면 5분 뒤 다시 시도하고, 세 번 실패하면 멈추고 **로그**에 남깁니다.

수출·수탁 건, 자사에 준 견본품, 공급받은자 사업자번호가 없는 줄은 보고 대상이 아니어서 싣지 않습니다.

## 날짜 하나 다시 받기

1. **대시보드** › **할 일**에서 받을 날짜 카드의 `⋯` 메뉴를 엽니다.
2. **데이터 받아오기**를 누릅니다.
3. 카드가 **조회 중** · **바코드 원천 대조**로 바뀌었다가 결과 상태로 바뀝니다.

이미 실린 날은 원천과 대조만 합니다. 원천이 바뀐 날은 덮지 않고 **변경 확인 필요**로 남깁니다. 다시 싣는 방법은 아래 "원천이 바뀐 날 다시 싣기"를 봅니다.

## 공급일자를 정해 받기

1. 사이드바 **예외 처리**에서 **데이터 가져오기**를 누릅니다.
2. 위쪽에서 **직접 연결**을 고릅니다. 연결을 미리 보려면 오른쪽 **테스트**를 누릅니다. 응답 시간이 보이면 연결된 것입니다.
3. **공급일자**를 고릅니다.
4. **직접 연결로 공급내역 조회**를 누릅니다.
5. 진행 단계와 활동 로그가 화면에 보입니다. 끝나면 **대시보드**에서 그날 카드를 확인합니다.

**릴레이**는 중계 서버를 거치는 예비 경로입니다. 어떤 경로를 쓸지는 관리자가 **데이터소스**에서 정합니다([설정과 사용자 관리하기](/kpis-dsr-api/user-guide/admin-features)).

## 원천이 바뀐 날 다시 싣기

1. **대시보드** › **할 일**에서 **변경 확인 필요** 카드의 `⋯` 메뉴를 열고 **변경 내용 확인**을 누릅니다.
2. 원천과 적재본의 갑지 줄, 을지 줄, 수량 합계, 금액 합계와 차이를 봅니다.
3. 그날의 상태에 따라 아래 가운데 하나를 고릅니다.

| 그날 상태 | 고를 버튼 | 결과 |
| --- | --- | --- |
| 보고 전, 사람이 고치지 않음 | **원천으로 다시 싣기** | 지금 원천으로 그날을 다시 싣습니다 |
| 보고 전, 사람이 고침 | **고친 내용 버리고 다시 싣기** | 고친 내용이 사라지고 원천으로 다시 싣습니다 |
| 보고함 | 줄마다 처리 | 통째로 다시 싣지 않습니다. 새 줄, 바뀐 줄, 사라진 줄을 따로 보여 줍니다 |

4. 보고한 날이면 줄마다 처리합니다.
   - 새 줄은 **새 줄만 덧붙여 싣기 → 추가 보고**로 싣고 보고합니다.
   - 바뀐 줄은 정정 기한 안의 출고면 **정정 줄 만들기**, 사라진 줄은 **취소 줄 만들기**를 누릅니다.
   - 기한이 지났거나 반품·폐기 줄이면 반송신청을 합니다([반송 줄 고쳐 다시 보고하기](/kpis-dsr-api/user-guide/return-management)).
5. 줄마다 처리를 마쳤으면 **처리 끝 — 원천 변경 확인**을 누릅니다. 다음 조회부터 지금 원천을 기준으로 봅니다.

> **참고:** 자동 보고가 켜져 있으면 보고한 날의 원천 변경 가운데 정정할 수 있는 것은 서버가 정정·취소·새 줄을 만들어 보냅니다. 정정할 수 없는 칸(거래처, 공급일 등)이 바뀐 줄만 사람이 위 절차로 처리합니다.

## 엑셀 파일 올리기

바코드 서버를 읽을 수 없을 때 쓰는 예비 방법입니다.

1. **데이터 가져오기**에서 **엑셀**을 고릅니다.
2. 파일 이름에 "갑지" 또는 "을지"가 들어가게 맞춥니다. 이름으로 갑지와 을지를 나누고, 나눌 수 없는 파일은 빼고 올립니다.
3. 파일을 끌어다 놓거나 칸을 눌러 고릅니다. .xlsx, .xls, .csv를 받습니다.
4. 을지가 없는 날짜가 있으면 **을지 없이 업로드할까요?** 창이 뜹니다. 갑지만 올리려면 **을지 없이 업로드**를, 아니면 **취소**를 누릅니다.

공급일자는 갑지 N열(공급일자)에서, 없으면 파일 이름에서 읽습니다. 이미 저장된 날짜는 올리지 않습니다. 그날을 다시 올리려면 먼저 **데이터 관리**에서 지웁니다([갑지·을지 고치기](/kpis-dsr-api/user-guide/data-editing)).

## 결과 확인

- 날짜 카드에 **보고 전**이 보이고 `⋯` 메뉴의 갑지 건수가 0보다 크면 실린 것입니다.
- 엑셀은 올린 뒤 "N개 날짜 업로드 완료"와 저장한 갑지 행 수가 알림으로 보입니다.

## 잘 안 될 때

| 증상 | 조치 |
| --- | --- |
| **자료 확인 필요** · **최근 수집 실패** | **데이터소스**에서 연결을 확인한 뒤 다시 받습니다 |
| **테스트**가 **실패** | **데이터소스**에서 경로 설정을 확인합니다 |
| 엑셀 "분류 불가 파일" 알림 | 파일 이름에 갑지·을지를 넣습니다 |
| 엑셀 "갑지 없음" | 그날 갑지 파일을 함께 올립니다 |

그 밖은 [문제 해결](/kpis-dsr-api/admin-guide/troubleshooting)을 봅니다.
