# 대시보드

사이드바의 **대시보드**에서 날짜별 보고 여부와 공급 현황을 확인합니다.

## 적기보고율

상단 요약 줄은 현재 한국 시간 기준 **접수 분기**를 명시하고, 자사·타사 적기보고율과 목표 95%, 각각의 목표 대비 차이를 보여줍니다. 아래 공급 현황에서 고른 달과 다른 범위이므로 분기 표시를 확인하세요.

값은 심평원 조회 자료를 수량 기준으로 집계합니다. 월별 비율을 단순 평균하거나, 엑셀 다운로드·수기 완료 표시로 계산하지 않습니다. 자료 없음·키 미설정·부분 조회 실패를 0%나 목표 충족으로 표시하지 않습니다. 개발 환경의 수치는 검증계임을 표시합니다. 계산·원천·갱신 정보는 `ⓘ`에서 확인합니다.

## 할 일

월~금 5일을 한 줄로 표시합니다. **주간 / 월 달력**, 날짜 선택, 이전·다음 기간, **이번 주**로 이동합니다. 한국 시간의 오늘 날짜를 강조하며 토·일은 화면에서 제외합니다. 토·일에 실제 공급이 있으면 별도로 알리고 일괄 검토에 포함합니다.

카드의 큰 글자는 그 날짜의 보고 상태입니다.

| 상태                         | 뜻                                                      |
| ---------------------------- | ------------------------------------------------------- |
| 보고 전                      | 적재된 자료가 있으며 아직 보고하지 않음                 |
| 완료 확인 전 · 엑셀 다운로드 | 다운로드 이력이 있으나 수기 제출 완료 표시는 하지 않음  |
| 보고 완료 · 수기 완료 표시   | 사용자가 포털 제출을 마쳤다고 표시함                    |
| 보고 완료 · API 접수 확인    | 심평원 응답으로 접수를 확인함                           |
| 변경 확인 필요               | 원천이나 이전 보고·다운로드 자료와 현재 자료가 다름     |
| 결과 확인 필요               | 전송 결과가 불명확해 재전송보다 결과 확인이 먼저 필요함 |

갑지 건수·구분별 엑셀·수기 완료 표시와 해제·데이터 받아오기·회사 휴무 조작은 날짜의 `⋯` 메뉴에 있습니다. 공휴일이나 회사 휴무는 붉은 날짜로 표시하지만, DB에 공급 자료가 있으면 보고 대상과 상태를 유지합니다.

## API 보고와 일괄 검토

날짜의 **API 보고** 또는 **일괄 보고 검토**를 누르면 실제 대상·이미 접수된 자료·보류 날짜를 먼저 확인합니다. 다운로드 이력이 있는 날은 포털 미제출 여부를 확인해야 하며, 이미 제출했거나 알 수 없으면 그대로 전송할 수 없습니다. 다운로드 뒤 자료가 달라졌으면 변경 내용도 확인해야 합니다.

운영 전송은 검토 팝업의 확인을 거칩니다. 검토 중 자료나 수기 완료 표시가 바뀌면 동의가 무효화되므로 다시 검토합니다. API 접수 자료는 신규 전송에서 제외하고, 접수 뒤 변경은 정정·취소 절차에서 확인합니다. 결과 미확인이 생기면 후속 전송을 보류합니다. 보고 상세 화면도 같은 검토 절차를 사용합니다.

## 공급 현황

제목 오른쪽의 **일 / 월 / 연 → 공급구분 → 그래프 / 표 / 둘 다**로 표시를 바꿉니다. 그래프와 표는 같은 기간·구분·집계를 사용합니다. 금액 막대에 마우스를 올리면 갑지 건수를 함께 표시하며, 오래된 집계의 접수건수는 갑지 줄 수와 구분합니다.

선택한 연도나 월을 다시 누르면 하위 기간으로 내려갑니다. 경로와 선택 해제, Escape로 이동할 수 있습니다. 자료가 없는 기간을 0으로 단정하지 않으며, 월·분기·연 누적과 기존 심평원 집계 확인 기능은 펼쳐 볼 수 있습니다.
