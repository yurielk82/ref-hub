# 외부 입력과 유비스트 자료 올리기

KPI 자료는 대부분 원천에서 자동으로 들어옵니다. 원천에 없는 공식 값과 유비스트 원외처방 자료만 관리자가 직접 넣습니다. 이 쪽은 그 두 가지를 넣는 방법입니다.

## 시작 전에 필요한 것

- 관리자 권한. 두 화면 모두 **관리자 설정** 메뉴에 있습니다.
- 외부 입력은 넣을 연도·월과 값. 유비스트 업로드는 유비스트에서 내보낸 엑셀 파일(.xlsx).

## 외부 입력값 넣기

월간 KPI의 계획값 가운데 원천에 없는 값을 넣습니다. 지금 넣는 값은 **영업반품률**(%)과 **할인 (음수)**(백만원) 두 가지입니다. 국내 매출 목표와 수금 목표는 원천에서 자동으로 들어오므로 넣지 않습니다.

1. **관리자 설정** 메뉴의 **입력·규칙** 묶음에서 **외부 입력**을 엽니다.
2. 넣을 연도와 월을 고릅니다. 처음에는 이번 달입니다.
3. **영업반품률**은 % 숫자로 넣습니다. 예를 들어 1.3%면 `1.3`을 넣습니다.
4. **할인 (음수)** 는 백만원 단위 음수로 넣습니다.
5. **저장**을 누릅니다.

저장하면 그 기간의 월간 KPI 값을 바로 다시 계산합니다.

같은 묶음의 **소송처 관리**에서는 소송 중인 거래처와 그 **고정 잔고**를 등록합니다. 채권 지표의 소송처 제외 잔고가 이 명단을 씁니다.

## 유비스트 원외처방 자료 올리기

유비스트 자료는 경쟁 제품까지 든 약품 단위 월 처방 자료입니다. 시장 화면의 점유율·성장지수·제품 행렬을 처방 기준으로 비교하는 데 씁니다. 유비스트는 매달 초에 지난달 자료를 내므로 한 달에 한 번 올립니다.

1. **관리자 설정** 메뉴의 **업로드** 묶음에서 **유비스트 업로드**를 엽니다.
2. **유비스트 자료 선택 가이드**를 읽고, 유비스트에서 그대로 받습니다. 처음 한 번은 최근 60개월, 그 뒤로는 매달 최근 13개월(지난달까지)입니다.
3. **유비스트 엑셀 파일**에 받은 파일을 고릅니다. 열이나 줄을 고치지 않은 파일 그대로 올립니다.
4. **유비스트 파일 미리보기**에서 달과 줄 수를 확인합니다.
5. **올리기**를 누릅니다.
6. 이전보다 줄 수가 크게 준 달이 있으면 **줄 수가 크게 주는 달 확인**이 나옵니다. 파일이 맞으면 **그래도 반영**, 아니면 **취소**를 누릅니다.

유비스트 가이드가 정한 받을 자료는 아래와 같습니다.

| 항목 | 내용 |
| --- | --- |
| 단위 | 약품(제품 + 함량 + 제형). 브랜드 단위가 아닙니다. |
| 범위 | 전체 시장, 필터 없음. 너무 크면 자사 제품이 든 ATC 분류 전부 |
| 값 | 처방조제액(원), 처방량. 처방건수가 있으면 함께 |
| 함께 받을 칸 | 제조사, 판매사, 제품명, 약품명, ATC, 성분, 제형, 투여경로, 급여구분, 보험코드 |

같은 달을 다시 올리면 그 달은 새 파일로 바뀝니다. 올리는 도중에 끊기면 아무것도 바뀌지 않습니다.

## 결과 확인

- 외부 입력은 **월간 KPI**에서 그 달 계획값이 바뀌었는지 봅니다.
- 유비스트 업로드는 **유비스트 업로드 이력**에 이번 파일이 올라왔는지 봅니다. **원본 자료** 메뉴의 **데이터 갱신 현황**에서 유비스트 줄이 정상인지도 확인합니다.

## 잘 안 될 때

- 유비스트 파일이 읽히지 않으면 유비스트에서 내보낸 엑셀을 열어 고치거나 다시 저장하지 않았는지 확인합니다. 원본 파일을 다시 받아 올립니다.
- 외부 입력을 저장했는데 월간 KPI가 그대로면 잠시 뒤 새로고침합니다. 계속 그대로면 [문제 해결](/pharmkpi/admin-guide/troubleshooting)을 봅니다.
