# 도메인 문서

Matt 스킬이 코드를 살피기 전에 읽는 도메인 문서와 읽는 법. 이 저장소는 단일 맥락이다(`GLOSSARY.md` 하나 + `docs/adr/`).

## 살피기 전에 읽는다

- 저장소 뿌리의 **`GLOSSARY.md`**(없으면 용어가 정해질 때 `/domain-modeling`이 만든다).
- **`docs/adr/`**: 손댈 영역에 걸린 ADR(아직 없다 — 결정이 정해질 때 `/domain-modeling`이 만든다).
- 저장소 고유 규칙: `AGENTS.md`.

없는 파일은 **조용히 넘어간다**. 없다고 알리거나 먼저 만들자고 하지 않는다.

## 용어를 따른다

결과물(이슈 제목·리팩터링 제안·가설·시험 이름)에서 도메인 개념을 부를 때는 위 문서의 말을 쓴다. 문서가 피하는 동의어로 바꾸지 않는다. 필요한 개념이 없으면 새 말을 지어낸 것인지, 실제 빈칸인지 따져 빈칸이면 `/domain-modeling`에 남긴다.

## ADR과 어긋나면 드러낸다

결과가 기존 ADR과 어긋나면 말없이 덮지 않고 밝힌다.
