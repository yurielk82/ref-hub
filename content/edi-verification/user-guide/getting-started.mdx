# 시작하기

검토 집계 화면에 로그인해 이번 달 EDI 검토 진행 상황을 확인합니다.

## 시작 전에 필요한 것

화면을 열려면 다음이 필요합니다.

- 허용 목록에 등록된 Google 계정. 목록에 없는 계정은 로그인해도 들어갈 수 없습니다.
- **검토 실행** 화면에서 실행 버튼을 쓰려면 실행 권한 계정이어야 합니다. 그 밖의 허용 계정은 보기만 할 수 있습니다.
- 검토 집계 화면 주소. 공개하지 않는 주소라 오너에게 받습니다.

## 로그인하기

1. 검토 집계 화면 주소를 엽니다. 로그인 화면에 세 단계 검증 그림과 **검증 결과 조회** 안내가 보입니다.
2. **Google 계정으로 로그인**을 누릅니다.
3. 허용된 Google 계정을 고릅니다.
4. **병원 현황** 화면이 열리면 로그인이 끝난 것입니다.

## 이번 달 상황 보기

1. **병원 현황** 맨 위 월 선택에서 검토한 달을 고릅니다. 처음에는 가장 최근 달이 열립니다.
2. 요약 숫자에서 **보류**와 **승인불가** 병원 수를 확인합니다.
3. 병원 표에서 **판정** 칩의 **보류**를 눌러 처리할 예외만 봅니다.
4. 병원 행을 펼쳐 처방월·첨부 쪽별 대조 결과, 비고, 근거 사진을 확인합니다.
5. 승인한 자료의 미비점을 보려면 왼쪽 메뉴에서 **문제점 비율**을 엽니다.

각 칸의 뜻은 [검토 집계 화면](/edi-verification/review-workspace)에 있습니다.

## 결과 확인

병원 현황 제목 아래에 마지막 집계 시각이 보이고, 요약 숫자와 병원 표가 채워져 있으면 정상입니다. 새 검토 기록은 들어온 뒤 5분 안에 반영됩니다.

## 잘 안 될 때

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 로그인 화면에 "로그인에 실패했습니다"가 보입니다 | 허용 목록에 없는 계정이거나 Google 로그인이 끝나지 않았습니다 | 허용된 계정인지 확인하고 다시 로그인합니다. 계정 추가는 오너에게 요청합니다. |
| 한동안 쓰다 보면 로그인 화면으로 돌아갑니다 | 로그인 유지 시간 8시간이 지났습니다 | 다시 로그인합니다. |
| **검토 실행** 화면에 "이 계정은 보기만 할 수 있습니다."가 보입니다 | 실행 권한 계정이 아닙니다 | 보기만 하려면 그대로 씁니다. 실행이 필요하면 실행 권한 계정으로 로그인합니다. |
| 월 선택에 원하는 달이 없습니다 | 그달 저장 검증을 마친 기록이 아직 없습니다 | 검토 기록이 올라온 뒤 5분 안에 그달이 생깁니다. |
| 방금 저장한 병원이 표에 없습니다 | 아직 5분 갱신 전이거나 저장이 재조회로 확인되지 않았습니다 | 5분 뒤 다시 엽니다. 그래도 없으면 [사람이 볼 건 검토하기](/edi-verification/user-guide/review)의 저장 확인 절차를 봅니다. |

> 확인 기준: 2026-11-18, cso-edi-review 저장소의 `report/` 기준.
