# 문제 해결

> **참고:** CSO 정산 포털의 정산 업무는 2026-09-29에 다른 정산 시스템으로 옮겼습니다. 이 쪽은 운영 당시 구성의 기록입니다.

운영 중 자주 나온 문제를 증상별로 정리합니다. 회원사가 직접 풀 수 있는 문제는 [자주 묻는 질문](/csoweb/user-guide/checklists)에 있습니다.

## 로그인과 계정

| 증상 | 원인 | 조치 |
|------|------|------|
| "승인 대기 중입니다. 관리자 승인 후 로그인 가능합니다." | 가입 승인 전입니다. | **회원 관리**의 **회원 목록**에서 서류를 확인하고 **승인**합니다. |
| "로그인 5회 실패로 계정이 잠겼습니다." | 비밀번호를 다섯 번 틀렸습니다. | 회원사가 자동 발송된 메일의 링크로 새 비밀번호를 정합니다. 메일을 못 받으면 관리자가 **비밀번호 초기화**를 합니다. |
| 로그인 직후 다시 로그인 화면이 나옴 | 브라우저가 쿠키를 막았거나 24시간 세션이 끝났습니다. | 쿠키를 허용하고 다시 로그인합니다. 시크릿 창이면 일반 창에서 시도합니다. |
| 관리자 화면 메뉴가 안 보임 | 계정 등급이 **관리자**나 **뷰어**가 아닙니다. | 다른 관리자가 **회원 정보 수정**의 **회원 등급**을 바꿉니다. |
| 관리자 화면에서 저장·업로드가 거절됨 | **뷰어** 등급은 조회만 할 수 있습니다. | 변경이 필요하면 **관리자** 등급 계정으로 합니다. |

## 회원사가 자료를 못 봄

| 증상 | 원인 | 조치 |
|------|------|------|
| **조회 가능한 정산 데이터가 없습니다** | 그 사업자번호에 CSO 매칭이 없습니다. | **거래처 매핑** 탭에서 **새 매핑 추가**로 정산서 표기를 잇습니다. |
| 매칭이 있는데 자료가 없음 | 매칭 표기와 정산서 **CSO관리업체** 표기가 글자 하나라도 다릅니다. | 정산서 표기를 새 꼬리표로 더합니다. 기존 표기는 지우지 않습니다. |
| 특정 달이 정산월 목록에 없음 | 그 달이 **조회 기준 연월**보다 앞섭니다. | **데이터 관리**의 **정산서 조회 제한**에서 기준 연월을 확인합니다. |
| 정산월 목록이 통째로 비었음 | **EDI 검토기간 전체 차단**이 켜져 있습니다. | 검토가 끝났으면 **전체 차단 해제**를 누릅니다. |
| "일일 다운로드 횟수(5회)를 초과했습니다." | 회원사의 하루 엑셀 다운로드 한도입니다. | 다음 날 다시 받거나, 관리자가 **마스터 조회**에서 받아 전달합니다. |

## 정산서 업로드

| 증상 | 원인 | 조치 |
|------|------|------|
| 파일이 올라가지 않음 | `.xlsx`·`.xls`가 아니거나 25MB를 넘습니다. | 엑셀 통합 문서로 다시 저장하고 불필요한 시트를 지웁니다. |
| **필수 컬럼 누락** | **사업자번호**나 **정산월** 열이 짝지어지지 않았습니다. | **컬럼 매핑 확인** 창에서 두 열을 직접 고릅니다. |
| 일부 열이 비어 들어감 | SIT 양식의 열 이름이 바뀌어 자동 짝짓기가 빗나갔습니다. | 매핑 창의 **매칭율**이 낮은 줄을 직접 고른 뒤 다시 올립니다. 같은 달은 통째로 바뀌므로 다시 올리면 됩니다. |
| 금액이 원본과 다름 | 업로드 때 숫자 칸을 잘못 읽었습니다. | **데이터 관리**의 합계를 원본과 대조하고, 다르면 그 달을 지운 뒤 원본을 다시 올립니다. |

## 메일

| 증상 | 원인 | 조치 |
|------|------|------|
| 메일이 **큐 대기**에서 안 움직임 | SMTP 방식인데 이메일 워커가 멈췄습니다. | 서버에서 이메일 워커 서비스 상태와 저널 기록을 보고 다시 시작합니다. |
| 큐가 있는데 워커가 "page not found"를 냄 | Supabase REST 서버가 발송 대기열 함수를 아직 모릅니다(스키마 캐시). | Supabase REST 서버에 스키마 다시 읽기 신호를 보낸 뒤 이메일 워커를 다시 시작합니다. |
| Resend 발송이 실패함 | API 키가 만료됐거나 발송 한도를 넘었습니다. | **이메일 이력**의 오류 내용을 보고 키를 바꾸거나 SMTP로 돌립니다. |
| **연결 테스트**가 실패함 | SMTP 정보가 틀렸거나 워커가 멈췄습니다. | **이메일 설정**의 호스트·포트·계정을 확인하고 워커 상태를 봅니다. |
| 발송 성공인데 받지 못함 | 스팸함으로 갔거나 회원 이메일이 틀렸습니다. | 스팸함을 확인하고 **회원 목록**에서 주소를 확인합니다. |

## 서버와 배포

| 증상 | 원인 | 조치 |
|------|------|------|
| 배포 뒤 화면이 오류를 냄 | 빌드 결과물이 덜 만들어졌거나 설정이 빠졌습니다. | 배포 스크립트가 직전 결과물로 되돌렸는지 확인합니다. 로컬에서 `pnpm run build`로 같은 오류가 나는지 봅니다. |
| **시스템 정보**에서 데이터베이스가 오류 | 공용 Supabase가 멈췄거나 키가 바뀌었습니다. | Supabase 컨테이너 상태와 환경 파일의 키를 확인합니다. |
| EDI 검토 OCR이 진행되지 않음 | OCR 워커가 멈췄을 수 있습니다. | OCR 워커 저널을 보고 다시 시작합니다. 자세한 내용은 [EDI 검증 매뉴얼](/edi-verification)에 있습니다. |
