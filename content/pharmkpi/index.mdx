# 영업 데이터 분석·보고 업무 개선

스프레드시트와 엑셀로 취합·관리하던 영업 자료를 조회·분석하고 보고하는 방식을 개선한 사례입니다. 제약 영업관리 실무를 바탕으로 필요한 시스템을 직접 구축해 활용하고 있습니다.

## 담당 범위와 현재 상태

- **담당 범위:** 영업 데이터 정리·분석, 집계 기준 점검, 업무 시스템 설계·구축·운영
- **현재 상태:** 사내 영업 데이터 시스템 운영 및 기능 개선 중
- **연관 업무:** 영업 활동·실적 분석(SFE), 판매·운영 계획(S&OP), 유통재고 관리 개선

## 기존 업무와 개선 내용

| 기존 업무                              | 개선 내용                                                 | 활용·진행 상태                         |
| -------------------------------------- | --------------------------------------------------------- | -------------------------------------- |
| ERP와 엑셀에서 자료를 각각 조회·취합   | 매출·수금·채권·재고 자료를 연계해 조회                    | 사내 실적 조회와 월간 보고에 활용      |
| 보고 자료마다 기간·대상·집계 기준 확인 | 기준월·비교 기간·대상 조건에 따른 조회·분석               | 표·그래프와 자료 내려받기 기능 개선 중 |
| 방문 기록과 매출·목표를 따로 확인      | 일보 방문 기록과 ERP 실적을 연결한 SFE 분석               | 월간 영업회의 자료에 활용              |
| 계획 검토에 필요한 자료를 각각 확인    | 매출 예측·시나리오 비교와 수요·공급·재고 검토 기능 구축   | S&OP 업무 적용·검증 진행 중            |
| 회계팀이 거래처 잔액을 따로 맞춰 봄    | 회계 보조원장 형식 거래처 원장과 월말 채권 대사           | 회계팀 메뉴 운영 중                    |
| 매달 엑셀 월 보고서 4종을 손으로 작성  | 원천 자료에서 다시 계산해 웹 화면과 원본 양식 엑셀로 제공 | 영업리포트 메뉴 운영 중                |
| 시장 자료를 공공 데이터에서 따로 정리  | 심평원·식약처 데이터 매일 자동 수집과 시장·경쟁 분석      | 시장 메뉴 운영 중                      |

## 영업 활동·실적 분석(SFE)

방문 기록과 매출·목표를 연계해 담당자·거래처별 영업 활동을 분석합니다. 방문 현황, 목표 달성률, 핵심 거래처 관리 현황을 월간 영업회의 자료로 정리하고 있습니다.

[영업 활동 분석 사례](/projects/sales-hq-sfe)

## 판매·운영 계획(S&OP)과 유통재고 관리

매출 예측과 가정별 시나리오 비교, 계획 저장, 수요·공급·재고 검토 기능을 구축했습니다. 현재는 업무 적용과 검증을 진행하며 유통재고 관리 업무의 효율화도 함께 추진하고 있습니다.

[판매 계획·재고 검토 개선 사례](/projects/sales-hq-snop)

## 부서별 업무 화면

같은 데이터에서 부서마다 필요한 화면을 나눠 제공합니다. 영업지원팀은 마감 현황과 실매출·수금·채권 홈, 회계팀은 거래처 원장과 월말 채권 대사, 영업본부는 월간 KPI와 SFE 회의 자료를 봅니다. 매달 손으로 만들던 엑셀 월 보고서 4종은 원천 자료에서 다시 계산해 원본 양식 그대로 내려받습니다.

[회계팀 거래처 원장·채권 대사](/projects/accounting-ledger) · [영업 월 보고서 자동화](/projects/monthly-sales-reports)

## 시장·경쟁 분석

심평원·식약처 공공 데이터를 매일 자동으로 모아 성분 시장 규모와 성장, 대조약·경쟁 제품, 주력 품목 시장, 생산실적을 봅니다.

[시장·경쟁 분석 사례](/projects/market-analysis)

## 운영 자동화

판매 마감을 감시해 반영 누락을 경고하고, 마감·아침 알림을 보냅니다. 거래처 사업자번호 약 2만 4천 개를 매일 새벽 국세청 API로 조회해 휴·폐업 상태를 확인하고, 재직자 계정을 자동으로 만듭니다.

## 자료 확인 기준

ERP 자료의 출처와 기간·대상·단위를 확인하고, 매출·반품·매출할인의 집계 기준을 정리합니다. 실제 업무 효과와 확인된 성과는 구분하며, 기능을 배포한 사실만으로 예측 정확도나 재고 개선 효과를 확정하지 않습니다.
