# 시작하기

이 쪽에서는 처음 로그인하는 방법과 화면 구성, 자주 쓰는 용어를 익힙니다.

## 시작 전에 필요한 것

- Google 계정
- 관리자의 사용자 승인. 처음 로그인하면 승인을 기다리는 화면이 보이고, 관리자가 승인해야 업무 화면이 열립니다.

KPI.의 KPIS 메뉴에서 열 때는 따로 로그인하지 않습니다. KPI.의 로그인과 권한(관리자·조회)을 이어받습니다.

## 로그인하기

1. 공급내역 시스템 주소로 접속합니다.
2. **Google로 계속하기**를 누릅니다. **카카오로 계속하기**와 **Apple로 계속하기**는 아직 쓸 수 없습니다.
3. Google 계정을 고르고 인증을 마칩니다.
4. 승인을 기다리는 화면이 보이면 관리자에게 승인을 요청합니다. 관리자는 **사용자관리**에서 승인합니다([설정과 사용자 관리하기](/kpis-dsr-api/user-guide/admin-features)).

승인된 계정이면 **공급내역 현황판**(대시보드)이 열립니다.

## 역할

역할은 관리자와 승인 사용자 두 가지입니다.

| 역할 | 할 수 있는 일 |
| --- | --- |
| 관리자 | KPIS로 보고하기, 결과 미확인 정리, 반송 줄 다시 보고, 반송신청, 자료 다시 싣기·새 줄 덧붙이기, 엑셀 다운로드와 수기보고 완료 표시, 설정 변경, 사용자 승인 |
| 승인 사용자 | 현황판과 보고 상태 보기, 주문·KPIS 대조 보기, KPIS 집계 다시 받기, KPIS 조회 |

데이터를 바꾸거나 KPIS로 보내는 일은 모두 관리자만 합니다. 관리자 전용 버튼 자리에는 "API 보고는 관리자가 합니다"처럼 안내 문구가 대신 보입니다.

## 화면 구성

### 사이드바

사이드바는 네 묶음입니다. 평소 일은 **대시보드**의 **할 일**에서 하고, 나머지 메뉴는 예외를 처리하거나 설정할 때 씁니다.

| 묶음 | 메뉴 | 쓰는 때 |
| --- | --- | --- |
| (맨 위) | **대시보드** | 날짜별 보고 상태, 적기보고율, 대조 결과를 볼 때 |
| (맨 위) | **KPIS 포털** | 심평원 업무포털을 새 탭으로 열 때 |
| 예외 처리 | **KPIS 보고** | 날짜 하나의 보고·반송·이력·로그를 다룰 때 |
| 예외 처리 | **주문·KPIS 대조** | 주문과 KPIS 접수가 다른 거래처를 찾을 때 |
| 예외 처리 | **데이터 가져오기** | 공급 자료를 직접 다시 받거나 엑셀로 올릴 때 |
| 자료 | **데이터 관리** | 날짜별로 저장된 갑지·을지를 열거나 지울 때 |
| 자료 | **마스터 DB** | 표준코드 마스터를 찾거나 공공데이터와 견줄 때 |
| 설정 | **KPIS 연동 키** | 보고 자격증명, 조회 키, 자동 보고를 설정할 때 |
| 설정 | **데이터소스** | 바코드 서버를 읽는 경로를 고를 때 |
| 설정 | **휴일 관리** | KPI.의 휴일 관리 화면을 새 탭으로 열 때 |
| 설정 | **사용자관리** | 사용자를 승인하거나 지울 때(관리자에게만 보임) |

날짜 하나를 열면 사이드바에 **공급구분**(출고·반품·폐기·정정·취소)과 그날의 갑지·을지·매칭·미매칭·오류·경고 건수가 함께 보입니다. **오류**나 **경고**를 누르면 첫 번째 해당 줄로 갑니다.

### 머리글

화면 위쪽에는 지금 화면 이름, 날짜 선택, **KPIS 공급내역 보고** 버튼이 있습니다. 날짜를 연 화면에서는 검색 칸(제품명 또는 표준코드), **내보내기**, **도구** 메뉴도 보입니다.

## 자주 쓰는 용어

| 용어 | 뜻 |
| --- | --- |
| 갑지 | 공급내역 한 줄. KPIS 보고 양식의 21칸(A~U)입니다 |
| 을지 | 갑지 줄에 딸린 일련번호(바코드) 목록 |
| 공급구분 | 출고, 반품, 폐기, 정정, 취소 |
| 원천 | 바코드 서버에 있는 공급내역. 이 시스템은 읽기만 합니다 |
| 적재본 | 원천에서 읽어 이 시스템에 실은 자료 |
| 미보고 | 아직 KPIS로 보내지 않은 줄 |
| API 접수 확인 | 심평원 응답으로 접수를 확인한 상태 |
| 엑셀 다운로드 | 보고 자료를 파일로 내려받은 상태. 제출이나 보고 완료를 뜻하지 않습니다 |
| 수기보고 완료 표시 | 사용자가 포털 제출을 마쳤다고 표시한 상태. API 접수 확인과 구분합니다 |
| 반송 | KPIS가 받지 않고 돌려보낸 줄. 사유 코드가 붙습니다 |
| 결과 미확인 | 보냈지만 KPIS에 닿았는지 모르는 줄. 다시 보내지 않고 결과부터 확인합니다 |
| 변경 확인 필요 | 보고했거나 내려받은 자료와 지금 자료가 달라 대조가 필요한 상태 |
| 보고 계획 | 보내기 전에 날짜별 대상과 제외·보류 사유를 확인하는 계획 |
| 적기보고율 | 심평원이 집계한 분기 기한 내 보고수량 비율. 자사·타사 허가분을 나눠 봅니다 |
| 물류 마감 | KPI.가 알리는 그날 출고 마감. 자동 적재가 이때 시작합니다 |
| 판매 마감 | KPI.가 알리는 판매 자료 마감. 보낸 뒤 검사가 이때 시작합니다 |
