# 검토 실행하기

프로엠알의 승인대기 병원을 받아 원본을 수집하고, AI 판정을 받아 근거가 분명한 행을 프로엠알에 저장합니다. 여러 병원을 차례로 돌리는 **연속 실행**을 주로 쓰고, 한 병원만 다룰 때는 병원별 버튼을 씁니다.

## 시작 전에 필요한 것

실행하기 전에 다음을 갖춥니다.

- 실행 권한이 있는 Google 계정으로 로그인한 상태. 다른 계정은 버튼이 꺼져 있습니다.
- 오너 PC의 브라우저가 켜져 있고, 그 브라우저에 프로엠알이 로그인된 상태. 서버는 이 브라우저를 원격으로 움직여 프로엠알을 읽고 저장합니다.
- 다른 검토 세션이 같은 브라우저를 쓰고 있지 않은 상태. 최근 10분 안에 다른 검토 세션이 브라우저를 썼으면 서버가 실행을 시작하지 않습니다.
- 한 번에 하나의 실행만 돌 수 있습니다.

## 연속 실행으로 여러 병원 처리하기

1. 왼쪽 메뉴에서 **검토 실행**을 엽니다.
2. **준비 점검**에서 **점검 실행**을 누릅니다. 브라우저가 **연결됨**, 프로엠알이 **로그인됨**으로 보이는지 확인합니다.
3. **대상 목록**에서 **승인대기 목록 받기**를 누릅니다. 병원마다 품목수, 처방합계, 지급액예상, 지급액확정, 주의사항, 이번 달 기록 여부가 채워집니다.
4. **연속 실행**의 **병원 수**에서 처리할 병원 수를 고릅니다. **1곳**, **5곳**, **20곳**, **지급액예상 있는 병원 전체**, **남은 전체** 가운데 하나입니다.
5. **방식**을 고릅니다. 판정만 보고 저장은 나중에 하려면 **AI 판정까지 (저장 안 함)**, 저장까지 하려면 **프로엠알 저장까지**를 고릅니다.
6. **연속 실행 시작**을 누릅니다. 진행 중에는 몇 번째 병원을 처리하는지 보입니다.
7. 중간에 멈추려면 **이 병원까지 하고 중지**를 누릅니다. 지금 병원을 끝낸 뒤 멈춥니다.

연속 실행은 병원을 다음 순서와 조건으로 고릅니다.

- 지급액예상이 있는 병원을 먼저 처리합니다. 지급액예상이 없는 병원은 승인해도 지급액이 생기지 않기 때문입니다.
- 이번 달에 이미 기록이 있는 병원은 건너뜁니다. 판정만 끝나고 저장하지 않은 쪽이 남은 병원은 저장 단계부터 다시 잡습니다.
- 지난달에 수집한 결과는 쓰지 않습니다. 달이 바뀌면 병원을 새로 수집합니다.
- 승인대기 흰색 행이 없는 병원은 AI를 부르지 않고 닫습니다.

## 한 병원만 처리하기

1. **대상 목록**에서 병원을 찾아 **원본 수집**을 누릅니다.
2. **수집 결과**에 그 병원이 나타나면 **AI 판정**을 누릅니다.
3. **저장 점검**을 누릅니다. 저장할 행 수와 상태가 보이면 저장할 수 있는 상태입니다.
4. **프로엠알 저장**을 누르고, 확인 창에서 진행을 고릅니다.

## 무엇이 저장되는가

저장은 다음 행만 대상으로 합니다.

- 수집할 때 승인대기였고 AI가 승인 또는 승인불가로 낸 행만 저장합니다. 수량이 다르면 고친 수량과 `수량 수정` 비고를 함께 저장합니다.
- AI가 승인대기로 남긴 행과 이미 처리된 행은 건드리지 않습니다.
- 저장 직전에 행의 코드·수량·상태가 수집 때와 다르면 그 쪽 전체를 저장하지 않습니다.
- 저장 뒤 처방 창을 다시 열어 계획한 상태·수량·비고가 모두 보일 때만 저장된 것으로 셉니다.

## 결과 확인

연속 실행 결과는 **연속 실행** 영역에서 확인합니다.

- 위쪽 칩은 **전체**, **승인대기 행 있던 병원**, **사람이 볼 병원**, **승인불가 저장**, **실패** 병원 수입니다. 칩을 누르면 아래 표가 그 병원만 보입니다.
- 표는 병원마다 **결과**, **저장한 행**, **승인불가 저장**, **사람이 볼 행**, **시각**을 보입니다.
- **수집 결과**에서 병원 이름을 누르면 정산 상세와 쪽별 원본, AI 판정(원본 수량 열, 원본 수량, 수정 수량, 저장할 비고)이 열립니다.
- **AI 판정 엑셀**로 저장된 AI 판정 전체를 내려받습니다.

저장된 병원은 [검토 집계 화면](/edi-verification/review-workspace)의 **병원 현황**에 바로 반영됩니다. **사람이 볼 병원**은 [사람이 볼 건 검토하기](/edi-verification/user-guide/review)로 이어서 처리합니다.

## 잘 안 될 때

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 버튼이 모두 꺼져 있습니다 | 실행 권한 계정이 아니거나 다른 실행이 돌고 있습니다 | 실행 권한 계정으로 로그인합니다. 다른 실행이 끝날 때까지 기다립니다. |
| 실행이 시작되지 않습니다 | 최근 10분 안에 다른 검토 세션이 같은 브라우저를 썼습니다 | 그 세션이 끝나고 10분 뒤 다시 시작합니다. |
| 실행이 바로 멈춥니다 | 오너 PC 브라우저 연결이 끊겼습니다 | 브라우저를 켜고 **점검 실행**으로 연결을 확인한 뒤 다시 시작합니다. |
| 몇 병원 뒤 멈춥니다 | 세 병원 연속으로 실패했거나 저장 중 오류가 났습니다 | **실패** 칩으로 해당 병원과 오류를 확인합니다. 저장된 부분은 다음 실행이 재조회로 확인하고 이어 갑니다. |
| 저장이 실패했는데 실행은 계속됩니다 | 처방 창이 열리지 않아 저장하지 못했습니다 | 그 병원은 대기열에 남습니다. 다음 실행이 행 상태를 다시 읽고 처리합니다. |
| **저장 확인 안 된 쪽**이 보입니다 | 저장 뒤 다시 연 처방 창이 계획과 달랐습니다 | 저장된 것으로 세지 않습니다. 그 병원은 다음 실행이 다시 잡습니다. 바로 확인하려면 프로엠알에서 그 쪽을 엽니다. |
| 실행 중이던 표시가 사라졌습니다 | 서버가 다시 시작되면 실행이 끝납니다 | **연속 실행 시작**으로 다시 시작합니다. 이미 저장한 병원은 건너뜁니다. |
| 원본이 일부만 수집됐습니다 | 한 번에 받는 원본 크기를 약 9MB로 묶어 나머지를 미룹니다 | 다음 실행이 미룬 원본을 이어서 받습니다. |

> 확인 기준: 2026-11-18, cso-edi-review 저장소의 `report/` 기준.
