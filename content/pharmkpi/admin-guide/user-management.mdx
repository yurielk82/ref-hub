# 사용자·권한 관리

계정을 만들고, 사람마다 볼 1차 메뉴를 정하고, 권한 요청에 답하고, 분기마다 권한을 점검합니다. 모든 작업은 관리자만 합니다.

## 권한 구조

권한은 프리셋 하나와 사람별 예외로 정합니다.

| 프리셋 | 볼 수 있는 것 |
| --- | --- |
| 영업사원 | KPI 화면을 열지 않습니다. 로그인하면 영업 일보 앱으로 갑니다. |
| 내근부서 | 프리셋에 정한 1차 메뉴 |
| 임원 | 프리셋에 정한 1차 메뉴 |
| 관리자 | 모든 메뉴와 **관리자 설정**, **원본 자료** |
| 없음 | 메뉴가 없습니다. 관리자가 사람별로 더한 메뉴만 봅니다. |

- 프리셋마다 어떤 메뉴를 여는지는 관리자가 **프리셋 편집**에서 정합니다.
- 내근부서·임원·없음인 사람은 프리셋에 메뉴를 더하거나 빼는 예외를 둘 수 있습니다.
- **SFE**, **S&OP**, **KPIS**는 프리셋에 넣지 않고 사람마다 켜고 끕니다.
- 새 계정은 프리셋 없음으로 시작합니다. 승인 대기 단계는 없고, 메뉴를 열기 전에는 아무 업무 화면도 보이지 않습니다.

메뉴 권한은 화면을 열 때마다 서버에서 다시 확인합니다. 메뉴에서 숨긴 화면도 권한이 없으면 주소로 열 수 없습니다.

## 계정이 생기는 경로

| 경로 | 생기는 계정 |
| --- | --- |
| 사원 동기화 | 원천의 사원 정보에 맞춰 입사자 계정을 만들고, 부서 이동·퇴사·재입사·만료를 반영합니다. 매일 새벽에도 자동으로 맞춥니다. |
| **사용자 추가** | 외부 컨설턴트처럼 사원이 아닌 사람의 계정을 관리자가 직접 만듭니다. |
| **회원가입** | 사용자가 로그인 화면에서 직접 만듭니다. |

사원 정보를 지금 바로 맞추려면 **사용자 관리**에서 **사원 동기화**를 누릅니다.

## 메뉴 권한 주기

1. **관리자 설정** 메뉴의 **시스템 설정** 묶음에서 **사용자 관리**를 엽니다.
2. **사원 회원** 또는 **직접·가입 회원** 탭을 고릅니다. 권한 없는 사람은 표 맨 위에 모여 있습니다.
3. 왼쪽 부서 목록이나 위쪽 검색 칸으로 사람을 찾습니다.
4. 그 사람의 **프리셋**을 고릅니다.
5. 프리셋과 다르게 열거나 닫을 메뉴가 있으면 그 칸을 **켜기** 또는 **끄기**로 바꿉니다.
6. 여러 사람을 한 번에 바꾸려면 줄을 고른 뒤 **고른 사람 프리셋 지정**과 **일괄 적용**을 씁니다.
7. **저장**을 누릅니다. 메뉴가 0개가 되는 사람이 있으면 확인 창이 뜹니다. 내용을 보고 **확인하고 저장**을 누릅니다.

바꾼 내용은 **저장** 전까지 화면에만 있습니다. 저장 전에 되돌리려면 **되돌리기**를 누릅니다.

## 권한 요청에 답하기

사용자가 **권한 요청 / 문의**로 보낸 요청은 **요청함** 탭에 모입니다. 탭 이름 옆 숫자가 처리하지 않은 건수입니다.

1. **요청함** 탭을 엽니다.
2. 요청 내용과 보낸 화면을 읽습니다.
3. 요청대로 열어 주려면 **승인**을 누릅니다.
4. 열어 주지 않으려면 **거절 + 답**을 누르고 이유를 적습니다. 답을 비우면 보내지 않습니다.
5. 문의에만 답하려면 **답장**을 씁니다.

다른 관리자가 먼저 처리한 요청은 목록을 다시 읽어 보입니다.

## 비밀번호 재설정

1. 사람의 줄에서 **비밀번호 재설정**을 엽니다.
2. 둘 가운데 하나를 고릅니다.
   - **재설정 메일 보내기**: 그 사람에게 비밀번호를 새로 정하는 링크를 메일로 보냅니다.
   - **임시 비밀번호 발급 (다음 로그인 때 변경)**: 임시 비밀번호를 만듭니다. 그 사람은 다음 로그인 때 새 비밀번호를 정해야 다른 화면으로 갑니다.
3. 임시 비밀번호를 만들었으면 **임시 비밀번호 복사**로 복사해 본인에게 전합니다. 창을 닫으면 다시 볼 수 없습니다.

## 정지와 만료

- 로그인을 막으려면 그 사람을 **정지**로 바꾸고 저장합니다. 다시 열려면 **정지 해제**를 씁니다.
- 기간을 정해 쓰는 계정은 **만료일**을 넣고 **만료일 저장**을 누릅니다. 만료일이 지나면 로그인이 막힙니다.
- 정지·만료된 사람은 로그인하면 **계정이 정지되었습니다. 관리자에게 문의해 주세요.** 안내를 봅니다.

## 분기 권한 점검

분기마다 권한이 아직 필요한지 점검하고, 필요 없는 사람의 권한을 회수합니다.

1. **사용자 관리** 위쪽 분기 점검 안내에서 **점검 시작**을 누릅니다.
2. 사람마다 **마지막 로그인**과 **최근 30일 접속 일수**를 봅니다.
3. 더 쓰지 않는 사람을 회수 대상으로 고릅니다.
4. **점검 완료**를 누릅니다. 회수 대상은 정지되고 점검 기록이 남습니다.

자기 자신이나 마지막 관리자는 회수할 수 없습니다. 점검 도중 다른 관리자가 회원을 바꿨으면 점검을 기록하지 않습니다. 새로 불러와 다시 점검합니다.

## 사용 현황과 메뉴 순서

- **사용 현황**은 메뉴별 방문 수·방문자 수, 아무도 열지 않은 화면, 90일 동안 접속하지 않은 계정을 보입니다. 점검 때 함께 봅니다.
- **메뉴 순서**는 1차 메뉴와 메뉴 목록의 표시 순서를 모든 사용자에게 똑같이 정합니다. 화면을 숨기거나 다른 1차 메뉴로 옮길 수도 있습니다. 숨긴 화면도 권한이 있으면 주소로 열립니다.
- 사용자 관리·메뉴 순서 같은 시스템 설정 화면은 **관리자 설정**에 고정되어 옮길 수 없습니다. 메뉴 배치만으로 일반 사용자가 관리자 기능을 얻지 않게 하기 위해서입니다.
