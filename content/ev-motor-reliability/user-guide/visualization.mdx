# 실측 데이터 차트 파일 만들기

실차 시험 엑셀 하나를 명령줄에서 판정하고, 판정 차트 여섯 장을 PNG 파일로 저장합니다. 보고서에 차트를 붙일 때 씁니다. 웹 화면은 차트 파일을 내려받는 기능이 없습니다.

## 시작 전에 필요한 것

차트를 만들려면 다음이 필요합니다.

- 저장소를 받은 PC와 Python 3.10 이상
- 저장소 최상위 폴더에서 `pip install -e .`로 설치한 분석 패키지
- [실측 데이터 올리기](/ev-motor-reliability/user-guide/data-upload)의 형식을 맞춘 `.xlsx` 파일

## 절차

1. 엑셀 파일을 저장소 최상위 폴더에 둡니다.
2. `analyze_sample.py`를 열고 `SAMPLE_FILE = ...` 줄의 파일 이름을 내 파일 이름으로 바꿉니다. 이 스크립트는 명령줄 인자를 받지 않고 이 값만 읽습니다.
3. 저장소 최상위 폴더에서 실행합니다.

   ```bash
   python analyze_sample.py
   ```

4. 화면에 **[1] 온도 프로파일**부터 **종합 판정**까지 출력되고, 만든 파일 경로가 나오면 끝입니다.

## 결과 확인

`data/reports/` 폴더에 PNG 여섯 장이 300 dpi로 생깁니다. 같은 이름의 파일이 있으면 덮어씁니다.

| 파일 | 내용 |
|------|------|
| `thermal_timeseries.png` | 모터·IGBT·히트싱크 온도 시계열 |
| `torque_speed_scatter.png` | 차량 속도-모터 토크 산점도 |
| `operating_distribution.png` | 속도 구간별 듀티 사이클과 토크 분포 |
| `thermal_margin.png` | 채널별 열적 한계 마진 막대 |
| `reliability_assessment.png` | IGBT 열 사이클 분포와 누적 손상 |
| `multichannel_damage.png` | 세 채널의 누적 손상 비교 |

명령줄 마지막 **종합 판정**에는 열적 판정과 최소 마진, 신뢰성 판정과 손상이 가장 큰 채널이 나옵니다. 각 값의 뜻은 [실측 데이터 판정 기준](/ev-motor-reliability/user-guide/sample-analysis)에 있습니다.

## 잘 안 될 때

- "파일을 찾을 수 없습니다"가 나오면 `SAMPLE_FILE` 값과 실제 파일 이름이 같은지, 저장소 최상위 폴더에서 실행했는지 봅니다.
- "필수 컬럼 누락"이 나오면 엑셀 3행의 열 이름을 고칩니다.
