# 내 정보 바꾸기

> **참고:** CSO 정산 포털의 정산 업무는 2026-09-29에 다른 정산 시스템으로 옮겼습니다. 이 쪽은 운영 당시 화면 기준 기록입니다.

회원사가 업체 정보, 연락처, 정산 계좌, 서류, 비밀번호를 바꾸는 방법입니다. 대상은 회원사 담당자입니다. 비밀번호는 바로 바뀌지만, 나머지 정보는 변경 요청으로 접수되어 관리자가 승인해야 반영됩니다.

## 시작 전에 필요한 것

- 로그인한 회원 계정
- 서류를 바꾸려면 새 서류 파일(PDF, JPG, PNG, 10MB 이하)

## 업체 정보 변경 요청하기

1. 오른쪽 위 계정 메뉴를 열고 **내 정보 수정**을 누릅니다.
2. **내 정보** 화면의 **내정보 수정** 카드에서 바꿀 칸을 고칩니다.
3. 서류를 바꾸려면 같은 카드에서 새 파일을 올립니다.
4. **변경 요청 제출**을 누릅니다.
5. "변경 요청 접수" 알림을 확인합니다.

요청은 관리자 승인 전까지 반영되지 않습니다. 그동안 기존 정보가 그대로 쓰입니다.

바꿀 수 없는 칸도 있습니다.

| 칸 | 바꿀 수 있나 |
|------|------|
| **사업자번호** | 바꿀 수 없습니다. 로그인 아이디입니다. |
| **권한** | 바꿀 수 없습니다. **관리자** 또는 **일반 업체**로 표시됩니다. |
| **가입일** | 바꿀 수 없습니다. |
| 업체명, 대표자명, 주소, 연락처, 이메일, 은행·계좌, 서류 | 변경 요청으로 바꿉니다. |

## 요청 결과 확인하기

**내정보 수정** 카드의 **최근 변경 요청**에 상태가 나옵니다.

| 상태 | 뜻 |
|------|------|
| **승인 대기** | 관리자가 아직 보지 않았습니다. 이 동안에는 새 요청을 낼 수 없습니다. |
| **승인됨** | 요청한 값이 회원 정보에 반영되었습니다. |
| **반려** | 관리자가 거절했습니다. **반려 사유**를 읽고 고쳐서 다시 요청합니다. |

**기존값 / 요청값 비교**에서 무엇을 바꾸려 했는지 다시 볼 수 있습니다.

> **참고:** 회원 정보에서 업체명을 바꿔도 지난 정산 자료의 업체 표기는 바뀌지 않습니다. 정산 자료는 정산서에 적힌 업체 표기로 회원사에 이어집니다. 자세한 내용은 [CSO 매칭](/csoweb/user-guide/equipment)에 있습니다.

## 비밀번호 바꾸기

1. **내 정보** 화면의 **비밀번호 변경** 카드로 갑니다.
2. **현재 비밀번호**를 입력합니다.
3. **새 비밀번호**와 **새 비밀번호 확인**을 입력합니다. 영문과 숫자를 섞어 6자 이상으로 만듭니다.
4. **비밀번호 변경**을 누릅니다.
5. "비밀번호 변경 완료" 알림이 나오면 끝입니다.

## 잘 안 될 때

- "승인 대기 중인 변경 요청이 있어 추가 수정이 차단되었습니다."가 나오면 앞 요청이 처리될 때까지 기다립니다. 급하면 관리자에게 알립니다.
- 사업자번호가 바뀐 경우에는 새 사업자번호로 다시 가입해야 합니다. 관리자에게 기존 계정 처리를 함께 요청합니다.
