# 모터 제어 시뮬레이션 실행하기

DC 모터나 PMSM 모델로 제어 응답을 시뮬레이션하고, 제어 게인을 자동으로 찾습니다. 실제 장비에 게인을 넣기 전에 응답을 미리 확인할 때 씁니다.

## 시작 전에 필요한 것

시뮬레이션에는 다음이 필요합니다.

- 승인된 대시보드 계정
- 연결 상태 표시줄의 Python API(**Oracle SSH**)가 **연결됨**

API가 **미연결**이면 **실행** 대신 **다운로드**로 같은 설정의 Python 스크립트를 받아 내 PC에서 돌릴 수 있습니다.

## 한 번 시뮬레이션하기

1. 왼쪽 메뉴에서 **시뮬레이션**을 누르고 **시뮬레이션** 탭을 엽니다.
2. **모터**에서 **DC** 또는 **PMSM**을 고릅니다.
3. **제어**에서 **속도**, **위치**, **토크** 중 하나를 고릅니다. DC 모터는 토크 제어를, PMSM은 위치 제어를 지원하지 않습니다. 이 조합은 흐리게 보이고 **미지원 조합** 안내가 뜹니다.
4. **모드**에서 **단일**을 고릅니다.
5. **제어 게인**과 **시뮬레이션 설정** 값을 넣습니다. 모터 저항·인덕턴스 같은 값을 바꾸려면 **모터 파라미터 (고급)** 항목을 펼칩니다.
6. **실행**을 누릅니다.

기본값은 다음과 같습니다.

| 입력 | 기본값 |
|------|--------|
| Kp(비례), Ki(적분), Kd(미분) | 1.0, 10.0, 0.01 |
| 목표 속도 | 1000 rpm |
| 목표 위치 | 3.14 rad |
| 시뮬레이션 시간 | 1.0 s |
| 시간 간격 dt | 0.0001 s |
| 공급 전압, DC 버스 전압 | 24 V |
| 부하 토크 | 0 N·m |
| 극 쌍수(PMSM) | 4 |

## 결과 확인

오른쪽에 두 가지가 나옵니다.

- **성능 지표**: 정상상태 값, 오버슈트, 정착 시간, 상승 시간, 정상상태 오차
- **시뮬레이션 결과** 차트: 속도(rpm), 전류(A), 목표값의 시간 변화

## 여러 조건을 비교하려면

- **배치**: 게인 묶음 여러 개를 한 번에 돌려 **배치 비교 결과** 표(PASS, WARN, FAIL)와 **응답 비교 그래프**로 비교합니다.
- **스윕**: 한 파라미터를 **최소**, **최대**, **스텝** 범위로 바꿔 가며 돌리고 **스윕 결과 — 정착시간 히트맵**과 **최적 파라미터 추천**을 봅니다.

## 게인 자동 찾기

1. **파라미터 최적화** 탭을 엽니다.
2. **모터 타입**에서 **DC 모터** 또는 **PMSM**을 고릅니다.
3. **최적화 방법**에서 **PID 최적화**, **Ziegler-Nichols**, **FOC 최적화** 중 하나를 고릅니다. PID·FOC 최적화는 Nelder-Mead 방법으로 게인 범위 안을 찾습니다.
4. 게인 범위와 **가중치**(**오버슈트**, **정착 시간**, **정상상태 오차**)를 정합니다.
5. **최적화 실행**을 누릅니다.
6. 결과 게인을 쓰려면 **시뮬레이션 게인에 적용**을 누릅니다. **시뮬레이션** 탭 입력값이 바뀝니다.

## 잘 안 될 때

- "에이전트 미연결" 알림이 뜨면 API 연결 상태를 봅니다.
- 연속으로 여러 번 실행해 막히면 1분 뒤 다시 실행합니다. 시뮬레이션과 최적화는 분당 실행 횟수 제한이 있습니다.
- 그 밖의 증상은 [문제 해결](/ev-motor-reliability/admin-guide/troubleshooting)을 봅니다.
