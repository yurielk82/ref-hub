# 사람이 볼 건 검토하기

3단계 담당자 검증을 합니다. AI가 승인대기로 남긴 행, 승인불가로 저장된 행, 문제처·고액처를 사람이 원본과 대조하고 프로엠알에서 확정합니다. 문제처·고액처는 AI 판정이 승인이어도 따로 검수합니다.

## 시작 전에 필요한 것

검토하기 전에 다음을 준비합니다.

- 프로엠알에 로그인한 브라우저.
- 검토 집계 화면의 **검토 기준**. 판단은 현재 확정 기준을 따릅니다.
- [검토 실행하기](/edi-verification/user-guide/upload-process)로 돌린 연속 실행 결과.

## 볼 병원 고르기

1. **검토 실행** 화면의 **연속 실행** 결과에서 **사람이 볼 병원** 칩을 누릅니다. 표의 **사람이 볼 행**이 그 병원에서 확인할 행 수입니다.
2. **승인불가 저장** 칩을 눌러 승인불가로 저장된 병원도 목록에 적어 둡니다.
3. **대상 목록**의 **지급액예상**·**지급액확정** 칸과 **주의사항**을 보고 고액처와 문제처를 고릅니다.
4. **수집 결과**에서 병원 이름을 눌러 정산 상세, 쪽별 원본, AI 판정의 근거를 먼저 읽습니다.

## 원본과 대조하기

1. 프로엠알에서 그 병원의 처방 창을 열고 병의원 주의사항을 함께 확인합니다.
2. 모든 대상 처방월과 첨부 쪽을 엽니다. 쪽 번호가 원본 인쇄 번호와 달라도 접근할 수 있는 첨부는 모두 봅니다.
3. 흰색 행만 대조합니다. 분홍색 시스템 제외 행은 바꾸지 않습니다.
4. 병원명, 기간, 품목코드, 제품명, 함량, 수량을 등록값과 견줍니다.
5. 원본 양식에서 인정할 수량 열을 정합니다. 처방횟수, 총사용량, Acting, 출고수량을 섞어 쓰지 않습니다.

## 판정하고 저장하기

판정은 다음 기준으로 정합니다. 자세한 규칙은 **검토 기준** 화면에 있습니다.

| 경우 | 판정 | 비고 예 |
| --- | --- | --- |
| 병원·기간·품목·수량이 맞고 다른 문제가 없습니다 | 승인 | `종이 프린트, 관인없음` |
| 수량이 실제로 다릅니다 | 원본 수량으로 고친 뒤 다른 문제를 보고 판정 | `수량 수정` |
| 원본의 병원명이 실제로 다른 기관입니다 | 승인불가 | `원본 병원명 불일치` |
| 원본이 도매상·약국의 판매·조제 자료입니다 | 승인불가 | `도매자료`, `약국 판매자료` |
| 기준에 없는 새 예외이거나 병원 동일성이 불분명합니다 | 승인대기 유지가 기본입니다. 2026-11 보류 재처리는 그달 방침(R20)에 따라 원칙적으로 승인합니다. | 구체적 사유를 짧게 |

1. 판정과 비고를 흰색 행에 입력합니다. 비고는 자료 형태와 핵심 특이사항만 두세 표현으로 씁니다. 전월 이월 같은 기존 비고는 지우지 않고 뒤에 붙입니다.
2. 그 쪽의 흰색 행 변경을 묶어 저장합니다. 주의사항 창이 뜨면 확인합니다.
3. 저장 뒤 상태, 비고, 미저장 0을 확인하거나 쪽을 다시 열어 반영됐는지 봅니다. 저장 버튼이 꺼진 것만으로 저장됐다고 보지 않습니다.
4. 확인한 내용과 시각을 검토 기록에 남깁니다. 저장 여부가 불분명하면 저장 미확인으로 남기고 완료로 세지 않습니다.

## 새 판단을 기준에 반영하기

기준에 없는 판단을 오너가 확정했을 때만 기준을 고칩니다.

1. 결정 이력에 오너 발언을 근거로 적용 조건, 확인 항목, 수량 기준, 승인 판단, 비고 문구, 적용 범위를 적습니다.
2. 한 병원의 사례인지 일반 규칙인지 적용 범위를 분명히 적습니다. 사례 판단을 다른 병원으로 넓히지 않습니다.
3. 기존 판단을 바꾸면 지우지 않고 대체 관계를 적습니다.
4. 현재 기준을 같은 때에 고칩니다. **검토 기준** 화면은 파일을 바로 읽으므로 고친 내용이 곧 보입니다.

AI가 관찰한 내용이나 확인하지 못한 의심은 기준에 넣지 않습니다. 원칙은 [검증 단계와 기준 관리](/edi-verification/criteria)에 있습니다.

## 결과 확인

검토 기록이 올라간 뒤 5분 안에 **병원 현황**에 그 병원이 나타나고 판정이 바뀌면 끝입니다. 모든 대상 처방월과 첨부 쪽을 끝낸 병원만 **검토 완료 병원**에 들어갑니다.

## 잘 안 될 때

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 저장했는데 병원 현황에 없습니다 | 검토 기록이 아직 올라가지 않았거나 저장이 재조회로 확인되지 않았습니다 | 프로엠알에서 쪽을 다시 열어 반영을 확인하고 검토 기록을 남깁니다. |
| 병원이 **검토 완료 병원**에 들어가지 않습니다 | 끝내지 않은 처방월이나 첨부 쪽이 남았습니다 | 행을 펼쳐 빠진 처방월·쪽을 찾아 검토합니다. |
| 다른 사람이 이미 처리한 행이 보입니다 | 기존 승인 행입니다 | 덮어쓰지 않습니다. 기존 승인을 다시 확인한 것은 새 승인으로 세지 않습니다. |
| 금액이 원본과 다릅니다 | 원본 금액과 당사 금액 차이입니다 | 품목과 수량이 맞으면 금액 차이만으로 보류하지 않고 수량·단가도 고치지 않습니다. |

> 확인 기준: 2026-11-18, cso-edi-review 저장소의 `criteria/`·`operations/` 기준.
