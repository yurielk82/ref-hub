# KPIS에 보고하기

자동 보고가 보내지 않은 날이나 사람이 확인해야 하는 날을 골라 KPIS OpenAPI로 직접 보고합니다. 포털에 엑셀로 낸 날을 기록하는 방법, 결과 미확인 줄과 빠진 줄을 정리하는 방법도 이 쪽에 있습니다.

## 시작 전에 필요한 것

- 관리자 계정. 승인 사용자는 보고 계획을 볼 수만 있습니다.
- **KPIS 연동 키**에 보고용 클라이언트 아이디·시크릿, 보고 사업자번호, API 보고 시작일이 들어 있어야 합니다([설정과 사용자 관리하기](/kpis-dsr-api/user-guide/admin-features)).
- 표에서 고치던 줄은 먼저 저장합니다. 저장하지 않은 수정이 있으면 보고를 시작할 수 없습니다.

> **주의:** 정부 전송은 되돌릴 수 없고 KPIS는 같은 내용을 다시 보내도 막지 않습니다. 결과 미확인 줄이 있는 날은 다시 보내지 말고 결과부터 확인합니다.

## 날짜 하나 보고하기

1. **대시보드** › **할 일**에서 보고할 날짜 카드의 **API 보고**를 누릅니다. 사이드바 **KPIS 보고**의 **보고** 탭에서 날짜를 고르고 **API 보고 검토**를 눌러도 같습니다.
2. **API 보고 검토** 창에서 공급구분별 **현재**, **API 접수**, **미보고**, **다운로드** 줄 수를 확인합니다.
3. 보류 사유와 주문 대조 결과를 읽습니다. 주문 대조는 주문 값으로 고친 줄 수와 이번에 뺀 줄 수를 보여 줍니다. 뺀 줄은 다음 보고 때 다시 견줍니다.
4. 그날 엑셀을 내려받은 적이 있으면 포털 제출 여부를 고릅니다. **포털에서 실제 제출하지 않았음을 확인합니다**를 고른 날만 보낼 수 있습니다. **이미 포털에서 제출했습니다**나 **제출 여부를 알 수 없습니다**를 고르면 중복 보고를 막으려고 그날은 보내지 않습니다.
5. 내려받은 뒤 자료가 바뀌었다면 바뀐 내용을 확인하고 **다운로드 후 변경 내용을 확인했습니다**에 표시합니다.
6. 이번에 보내지 않을 날은 **이 날짜를 이번 계획에서 제외**에 표시합니다.
7. 기한이 지난 새 줄이 있으면 늦은 보고 줄 수와 수량이 빨간 글자로 보입니다. 적기보고율이 떨어지는 것을 확인했으면 늦은 보고 확인란에 표시합니다. 고친 줄이라면 여기서 보내지 말고 [반송 줄 고쳐 다시 보고하기](/kpis-dsr-api/user-guide/return-management)의 반송신청으로 고칩니다.
8. 운영 서버로 보낼 때는 **선택한 자료를 심평원 운영 환경으로 전송합니다**에 표시합니다.
9. **API 보고 시작**을 누릅니다.

보고는 서버에서 진행되므로 창을 닫거나 다른 화면으로 가도 계속됩니다.

## 결과 확인

- 창에 "계획 처리가 끝났습니다. 날짜별 접수 결과를 확인하세요."가 보이면 보고가 끝난 것입니다.
- 날짜 카드가 **보고 완료** · **API 접수 확인**이면 모든 줄이 접수됐습니다.
- **KPIS 보고** › **보고** 탭의 표에서 공급구분별 **API 접수**, **반송**, **미보고** 줄 수를 봅니다.
- **이력** 탭에서 실행마다 보고일, 상태, 서버, 갑지·을지, 접수·반송·전송 수, 실행 시각을 봅니다. 줄을 누르면 단계 기록이 열립니다.

반송된 줄이 있으면 [반송 줄 고쳐 다시 보고하기](/kpis-dsr-api/user-guide/return-management)로 갑니다.

## 여러 날 한꺼번에 보고하기

1. **대시보드** › **할 일**에서 **일괄 보고 검토**를 누릅니다.
2. 날짜마다 위 2~8단계와 같이 확인합니다. 접수된 자료와 보류된 날짜는 보내지 않습니다.
3. **API 보고 시작**을 누릅니다.

## 결과 미확인 정리하기

통신이 끊기거나 결과 조회가 실패하면 그 줄은 결과 미확인으로 남고 다시 보내지 않습니다.

1. **KPIS 보고** › **보고** 탭에서 그날을 엽니다. 결과 미확인 줄이 API 접수번호별 묶음으로 보입니다.
2. **API 결과 다시 확인**을 누릅니다. 대부분 이 단계에서 접수나 반송으로 풀립니다.
3. 풀리지 않으면 **KPIS 포털**(심평원 업무포털)에서 그 묶음의 접수 여부를 확인합니다.
4. 접수됐으면 업무포털의 **심평원 접수번호 14자리**를 넣고 **접수 확인 — 접수로 기록**을 누릅니다.
5. 접수되지 않았으면 **미접수 확인 — 반송으로 돌리기**를 누릅니다. 그 줄은 반송 줄이 되고, **반송 처리** 탭의 **저장하고 반송 줄 다시 보고**로 보냅니다.

> **주의:** 미접수로 잘못 고르면 두 번 접수되고, 접수로 잘못 고르면 보고가 빠집니다. 업무포털에서 확인한 대로만 고릅니다.

## 빠진 줄 보고하기

포털로 낸 날에 빠진 줄이나 원천에 늦게 들어온 줄을 KPIS 집계와 견줘 보냅니다.

1. **KPIS 보고** › **보고** 탭에서 그날을 엽니다.
2. **KPIS에 없는 줄** 칸의 **KPIS 집계와 대조**를 누릅니다. 거래처별 KPIS 접수(줄 수·수량·금액)를 우리 보고분과 견줘, 모자란 만큼과 정확히 맞는 줄만 고릅니다.
3. "KPIS 집계와 모두 맞습니다."가 보이면 보낼 줄이 없습니다.
4. 고른 줄이 있으면 **빠진 N줄 보고 계획 만들기**를 누릅니다(N은 줄 수).
5. 열린 보고 계획을 확인하고 **API 보고 시작**을 누릅니다. 보내기 직전에 한 번 더 대조합니다.

맞는 줄 조합이 여럿이거나 KPIS가 우리 보고분보다 많으면 줄을 고르지 않고 이유만 보여 줍니다.

## 표준코드 정정 제안으로 보고하기

바코드 서버 품목 마스터의 포장 바코드가 틀리면 주문 대조가 그 줄을 보류해 보고되지 않습니다. 이때 **보고** 탭에 **표준코드 정정 제안**이 보입니다.

1. 제안된 줄의 지금 값과 고칠 값(화살표 오른쪽), 근거로 쓴 품목코드·ERP 코드·마스터 품명을 확인합니다. 제안은 바코드 품목코드와 ERP 주문 품목코드가 같고, ERP 표준코드가 검증숫자에 맞으며 표준코드 마스터에 있고, 고친 수량·금액이 주문과 같을 때만 나옵니다.
2. **고쳐서 보고 계획**을 누릅니다. 서버가 조건을 다시 확인한 뒤 줄을 고치고 그 줄만 담은 보고 계획을 엽니다.
3. **API 보고 시작**을 누릅니다.

조건이 하나라도 맞지 않으면 이유만 보이고 버튼이 없습니다. 이 기능은 줄을 자동으로 고치거나 보내지 않습니다.

## 포털에 엑셀로 낸 날 기록하기

API 보고 시작일 전 날짜나 포털에 직접 내야 하는 날은 엑셀로 내려받아 업무포털에 올립니다.

1. **대시보드** › **할 일**에서 날짜 카드의 `⋯` 메뉴를 엽니다.
2. **엑셀 다운로드** 아래 **출고**, **반품**, **폐기**, **정정**, **취소** 가운데 필요한 것을 누릅니다. 줄 수가 0인 구분은 누를 수 없습니다.
3. 내려받은 파일을 업무포털에 올려 제출합니다.
4. 제출을 마쳤으면 `⋯` 메뉴의 **수기보고 완료로 표시**를 누릅니다.

카드가 **보고 완료** · **수기 완료 표시**로 바뀝니다. 잘못 표시했으면 **수기보고 완료 표시 해제**를 누릅니다. 엑셀 내려받기는 자료를 바꾸지 않습니다.

## 자동 보고와의 관계

관리자가 **KPIS 연동 키**에서 **자동 보고**를 켜면 물류 마감 적재 직후와 밤 11시에 이 쪽의 보고 계획을 서버가 스스로 만들어 보냅니다. 사람이 하는 보고와 같은 사전점검·주문 대조·이미 접수 검사를 거칩니다. 자세한 동작은 [자동 보고 흐름](/kpis-dsr-api/admin-guide/report-flow)에 있습니다.

## 잘 안 될 때

| 보이는 문구 | 조치 |
| --- | --- |
| 보고용 클라이언트 아이디·시크릿이 없습니다 | 관리자가 **KPIS 연동 키**에 넣습니다 |
| 보고 사업자번호가 없습니다 | 관리자가 **KPIS 연동 키**에 넣습니다 |
| 저장하지 않은 수정이 있습니다 | 표의 수정을 저장한 뒤 다시 엽니다 |
| API로 보낼 미보고 줄이 없습니다 | 보낼 줄이 없습니다. 반송 줄은 **반송 처리** 탭에서 보냅니다 |
| 개발 서버(시험용) | 개발 서버로 설정돼 실제 보고가 되지 않습니다. **KPIS 연동 키**의 **서버**를 확인합니다 |
| 자료 또는 수기 완료 표시가 바뀌었습니다 | 창을 닫고 보고 대상을 다시 검토합니다 |

그 밖은 [문제 해결](/kpis-dsr-api/admin-guide/troubleshooting)을 봅니다.
