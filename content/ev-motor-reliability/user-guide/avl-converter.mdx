# AVL 시험 프로파일 변환하기

운전 프로파일 CSV를 AVL PUMA 시험기가 읽는 XML 시험 프로파일로 바꿉니다. 여러 CSV를 한 번에 바꿔 ZIP으로 받을 수 있습니다.

## 시작 전에 필요한 것

변환에는 다음이 필요합니다.

- 운전 프로파일 CSV. 첫 줄이 열 이름이고, 속도 명령·토크 명령·추가 명령 열이 있어야 합니다. 자동 매칭을 끄면 2·3·4번째 열을 씁니다. 인코딩은 UTF-8, CP949, EUC-KR 모두 읽습니다.
- 파일 하나당 50MB 이하.
- 기준 XML. 서버에 내장된 AVL XML 템플릿(10000 step, 0.1초 간격)을 기본으로 씁니다. 다른 템플릿을 써야 하면 그 XML 파일을 준비합니다.

로그인은 필요 없습니다.

## 1단계. CSV 올리기

![AVL 변환 첫 단계에서 운전 프로파일 CSV 네 개를 고른 화면](/assets/selected-portfolio/images/ev-motor-reliability/avl-converter-upload.webp)

1. 브라우저에서 `avl.dvsharp.com/avl-converter`를 엽니다. 화면 위에 **CSV 업로드**, **매칭 검토**, **결과** 세 단계가 보입니다.
2. **운전 프로파일 CSV 선택 (다중 가능)** 버튼을 누르고 CSV를 한 개 이상 고릅니다. 버튼이 "N개 CSV 선택됨"으로 바뀌고 파일 목록이 나옵니다.
3. 잘못 고른 파일은 그 줄의 **제거**를 누릅니다.
4. 내장 템플릿 대신 다른 기준 XML을 쓰려면 **고급: 다른 base XML 사용 (선택 사항)** 항목을 펼치고 **Custom AVL XML 선택**으로 XML을 고릅니다. 내장 템플릿으로 돌아가려면 **서버 default 사용**을 누릅니다.
5. **업로드 후 미리보기**를 누릅니다.

## 2단계. 매칭 검토와 옵션

![AVL 변환 둘째 단계에서 자동 매칭 결과 표와 변환 옵션을 보여 주는 화면](/assets/selected-portfolio/images/ev-motor-reliability/avl-converter-review.webp)

1. 위쪽 요약에서 XML의 step 수와 CSV의 행 수, 인코딩, 열 이름을 확인합니다.
2. **AUTO-MATCH 결과** 표에서 **속도명령**, **토크명령**, **추가명령 1**이 각각 맞는 CSV 열에 연결됐는지 봅니다. **점수**가 초록이면 0.9 이상, 노랑이면 0.6 이상, 빨강이면 그보다 낮습니다.
3. **변환 옵션**을 정합니다.
   - **Target Steps (상한)**: 바꿀 step 수의 상한입니다. 기본값은 10000입니다. CSV가 더 짧으면 CSV 길이만큼만 바꿉니다.
   - **min-match-score**: 자동 매칭 점수가 이 값보다 낮은 변수가 있으면 변환을 거부합니다. 기본값은 0.9이고, 0이면 검사하지 않습니다.
   - **AUTO-MATCH 사용**: 기본으로 켜져 있습니다. 끄면 2·3·4번째 열을 속도·토크·추가 명령으로 씁니다.
4. 기록 설정을 바꿔야 하면 **RECORDING SETTINGS (비우면 원본 유지)** 아래 **Storage Interval (s)**, **Max Recording Time (s)**, **Storage Name**, **Sampling Freq (Hz)** 칸을 채웁니다. 비워 두면 템플릿 값을 그대로 둡니다.
5. 기준 XML의 채널 설정을 확인하려면 **채널 78개 CSV export**를 누릅니다. 채널 목록이 CSV로 내려받아집니다.
6. **변환 실행**을 누릅니다. CSV가 여러 개면 버튼 이름이 **N개 일괄 변환**입니다.

## 3단계. 결과 받기

![AVL 변환 셋째 단계에서 CSV 네 개의 변환 결과와 다운로드 버튼을 보여 주는 화면](/assets/selected-portfolio/images/ev-motor-reliability/avl-converter-result.webp)

1. **변환 결과** 제목에서 성공·실패 개수를 확인합니다.
2. 표에서 파일별 **변환된 step**, **유지된 step**, **demand row**를 확인합니다. **유지된 step**은 CSV가 짧아서 원래 템플릿 값을 그대로 둔 step 수입니다.
3. 파일 하나만 받으려면 그 줄의 **XML**을 누릅니다. 모두 받으려면 **전체 ZIP 다운로드 (N개 XML)** 버튼을 누릅니다.
4. 다른 파일을 바꾸려면 **새 변환 시작**을 누릅니다.

## 결과 확인

변환이 끝나면 다음 파일을 받습니다.

| 파일 | 이름 |
|------|------|
| 파일별 XML | `converted_` 뒤에 CSV 파일 이름 |
| 전체 묶음 | `avl_converted_` 뒤에 세션 번호 앞 8자리, 확장자 `.zip` |
| 채널 목록 | `channels_` 뒤에 세션 번호 앞 8자리, 확장자 `.csv` |

결과 XML은 원본 XML 문서 형식과 줄 수를 그대로 두고 명령 값만 바꾼 파일입니다. 변환기는 저장한 XML을 다시 읽어 step 수와 모든 명령 값이 의도한 값과 같은지 확인한 뒤에만 결과를 냅니다.

> **주의:** 변환기는 명령 값이 장비가 허용하는 범위 안인지는 검사하지 않습니다. 시험기에 넣기 전에 속도·토크 명령 범위를 직접 확인합니다.

세션과 올린 파일은 서버 임시 폴더에 1시간 동안 남은 뒤 지워집니다. 결과는 그 안에 내려받습니다.

## 잘 안 될 때

- 화면을 열자마자 "세션 생성 실패"가 나오면 서버 쪽 문제입니다. 관리자에게 알립니다.
- 변환이 실패하면 매칭 점수가 **min-match-score**보다 낮은 변수가 있는지 봅니다. 매칭 규칙은 [AVL 변환 규칙](/ev-motor-reliability/user-guide/avl-conversion-rules)에 있습니다.
- 그 밖의 증상은 [문제 해결](/ev-motor-reliability/admin-guide/troubleshooting)을 봅니다.
